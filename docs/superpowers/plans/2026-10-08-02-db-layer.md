# Ф2 Слой БД: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Настоящий PostgreSQL (PGlite) в Web Worker за простым RPC: очередь запросов, сторож 3 с, песочница урока с превью без побочных эффектов, применением, отменой, сбросом и восстановлением после зависания или падения; интроспекция каталога для доски и словарь 15 частых ошибок.

**Architecture:** Один обработчик протокола `createRequestHandler` (PGlite + `dumpDataDir`/`loadDataDir`) работает и внутри `db.worker.ts`, и в процессе Node. Поверх любого транспорта (`RpcPort`) стоит `createRpcClient`: очередь «по одному», таймаут → `terminate` → `VS001`. `createWorkerClient` подключает его к настоящему Worker'у, `createNodeClient` к обработчику в процессе (тесты). `createSandbox` держит снапшот датасета в памяти, журнал применённых операторов и единый мьютекс; любое изменение базы (отмена, сброс, восстановление) = новый клиент из снапшота + повтор журнала. React-слой: `SandboxProvider` создаёт песочницу после первого рендера, `useLessonSandbox` связывает её с уроком и `useLessonStore` (журнал в localStorage).

**Tech Stack:** `@electric-sql/pglite@0.5.8` (PostgreSQL 18.3), Vite 8 (worker `format: 'es'`), React 19, zustand 5 (`persist`), sonner (shadcn), Vitest 5 (проекты `node` и `dom`), Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-08-visual-sql-design.md`, разделы 5.4, 5.11, 5.12, 5.13, 5.14, 6.2, 9. Контракты: `docs/superpowers/plans/2026-10-08-00-contracts.md`, разделы 1, 4, 7 (`lesson.ts`), 11, 12, 13.

## Review Focus

1. Дамп без `checkpoint` сдвигает identity после каждой отмены и сброса (ученик видит id 34 вместо 7): тест «дамп и загрузка не сдвигают identity» (задача 2) и «undo возвращает и данные, и последовательности» (задача 4).
2. `COMMIT` внутри превью протекает в базу и ломает инвариант «превью не меняет базу»; сравнение по `transaction_timestamp()` его не ловит: тест «COMMIT внутри превью не протекает в базу» (задача 4).
3. Сторож: таймаут → `terminate`, текущий запрос и очередь получают `VS001`, новые вызовы `VS002`, песочница поднимается из снапшота с тем же журналом: тесты «по таймауту: terminate, текущий и очередь → VS001...» (задача 1), «после таймаута поднимается из снапшота и журнала» (задача 5), e2e «сторож прерывает зависший запрос...» (задача 10).
4. `order by ctid` без алиаса таблицы сортирует текстовый ctid, и строка `(0,10)` встаёт перед `(0,2)`, связь доски с трассой рвётся: тест «первые строки идут по ctid, а не по тексту ctid» (задача 6).

```ts
import { createRpcClient, type RpcPort } from './client';
import type { WorkerRequest, WorkerResponse } from './protocol';
import { type DbException, SANDBOX_CRASHED, SANDBOX_TIMEOUT } from './types';

// Подменный транспорт: тест сам решает, когда и что ответить
function fakePort() {
  const sent: WorkerRequest[] = [];
  let reply: (res: WorkerResponse) => void = () => {};
  let fail: () => void = () => {};
  const port: RpcPort = {
    post: (req) => void sent.push(req),
    onMessage: (cb) => {
      reply = cb;
    },
    onError: (cb) => {
      fail = cb;
    },
    terminate: vi.fn(),
  };
  const last = () => sent[sent.length - 1].id;
  const answer = (value: unknown) => reply({ id: last(), ok: true, value });
  const reject = (code: string) => reply({ id: last(), ok: false, error: { code, message: code } });
  return { port, sent, answer, reject, crash: () => fail() };
}
const tick = () => new Promise((r) => setTimeout(r, 0));
const code = (p: Promise<unknown>) =>
  p.then(
    () => 'ok',
    (e: DbException) => e.db.code,
  );

async function connected(timeoutMs = 50) {
  const f = fakePort();
  const pending = createRpcClient(f.port, { timeoutMs });
  await tick();
  f.answer(null); // init
  return { ...f, client: await pending };
}

describe('createRpcClient', () => {
  it('шлёт запросы строго по одному', async () => {
    const { client, sent, answer } = await connected();
    const a = client.query('select 1');
    const b = client.query('select 2');
    await tick();
    expect(sent.map((r) => r.type)).toEqual(['init', 'query']);
    answer({ fields: [], rows: [[1]] });
```

```ts
import { type DbError, DbException } from './types';

export type WorkerRequest =
  | { id: number; type: 'init'; dataDir?: Blob }
  | { id: number; type: 'query'; sql: string; params?: unknown[] }
  | { id: number; type: 'exec'; sql: string }
  | { id: number; type: 'dump' }
  | { id: number; type: 'version' };
export type WorkerResponse =
  | { id: number; ok: true; value: unknown }
  | { id: number; ok: false; error: DbError };

const TEXT_FIELDS = ['detail', 'hint', 'schema', 'table', 'column', 'constraint'] as const;

// DatabaseError из PGlite → DbError. Проверяем по форме, а не instanceof: ошибка может прийти из другого realm
export function toDbError(e: unknown): DbError {
  if (e instanceof DbException) return e.db;
  if (typeof e === 'object' && e !== null && typeof (e as { code?: unknown }).code === 'string') {
    const src = e as Record<string, unknown>;
    const err: DbError = { code: src.code as string, message: String(src.message ?? '') };
    for (const key of TEXT_FIELDS) if (typeof src[key] === 'string') err[key] = src[key];
    if (src.position !== undefined && src.position !== '') err.position = Number(src.position);
    return err;
  }
  // не ошибка Postgres (сбой wasm, баг в нашем коде): XX000 internal_error
  return { code: 'XX000', message: e instanceof Error ? e.message : String(e) };
}
```

`src/features/db/client.ts`:

```ts
import type { WorkerRequest, WorkerResponse } from './protocol';
import {
  type DbClient,
  type DbError,
  DbException,
  type QueryResult,
  SANDBOX_CRASHED,
  SANDBOX_TIMEOUT,
} from './types';

// Транспорт до обработчика: Worker в браузере, вызов в процессе в node, подделка в тестах
export interface RpcPort {
  post(req: WorkerRequest): void;
  onMessage(cb: (res: WorkerResponse) => void): void;
  onError(cb: () => void): void;
  terminate(): void | Promise<void>;
}
export interface WorkerClientOptions {
  dataDir?: Blob;
  timeoutMs?: number; // по умолчанию 3000
}
export interface RpcOptions extends WorkerClientOptions {
  initTimeoutMs?: number; // по умолчанию 30000
}

type Body = WorkerRequest extends infer R ? (R extends WorkerRequest ? Omit<R, 'id'> : never) : never;

const CLOSED: DbError = { code: SANDBOX_CRASHED, message: 'Песочница закрыта' };

export async function createRpcClient(port: RpcPort, opts: RpcOptions = {}): Promise<DbClient> {
  const timeoutMs = opts.timeoutMs ?? 3000;
  let nextId = 1;
  let death: DbError | null = null;
  let tail: Promise<unknown> = Promise.resolve();
  let current: {
    id: number;
    resolve(v: unknown): void;
    reject(e: unknown): void;
    timer?: ReturnType<typeof setTimeout>;
  } | null = null;

  // Клиент умирает один раз: текущий запрос и вся очередь отклоняются с причиной смерти
  function die(err: DbError): void | Promise<void> {
    if (death) return;
    death = err;
    if (current) {
      clearTimeout(current.timer);
      current.reject(new DbException(err));
      current = null;
    }
    return port.terminate();
  }

  port.onMessage((res) => {
    if (!current || res.id !== current.id) return;
    const c = current;
    current = null;
    clearTimeout(c.timer);
    if (res.ok) c.resolve(res.value);
    else c.reject(new DbException(res.error));
  });
  port.onError(() => void die({ code: SANDBOX_CRASHED, message: 'Worker песочницы упал' }));

  // Очередь: следующий запрос уходит только после ответа на предыдущий
  function send<T>(body: Body, ms = timeoutMs): Promise<T> {
    if (death) return Promise.reject(new DbException(CLOSED));
    const run = () =>
      new Promise<T>((resolve, reject) => {
        if (death) return reject(new DbException(death));
        const id = nextId++;
        const timer =
          ms > 0
            ? setTimeout(
                () => void die({ code: SANDBOX_TIMEOUT, message: `Запрос выполнялся дольше ${ms / 1000} с` }),
                ms,
              )
            : undefined;
        current = { id, resolve: resolve as (v: unknown) => void, reject, timer };
        port.post({ ...body, id } as WorkerRequest);
      });
    const p = tail.then(run);
    tail = p.catch(() => {});
    return p;
  }

  try {
    await send({ type: 'init', dataDir: opts.dataDir }, opts.initTimeoutMs ?? 30000);
  } catch (e) {
    await die(CLOSED);
    throw e;
  }

  return {
    query: (sql, params) => send<QueryResult>({ type: 'query', sql, params }),
    exec: (sql) => send<QueryResult[]>({ type: 'exec', sql }),
    dump: () => send<Blob>({ type: 'dump' }),
    version: () => send<string>({ type: 'version' }),
    close: async () => {
      await die(CLOSED);
    },
  };
}
```

`src/features/db/handler.ts`:

```ts
import { PGlite, type Results } from '@electric-sql/pglite';
import { toDbError, type WorkerRequest, type WorkerResponse } from './protocol';
import type { QueryResult } from './types';

function toResult(r: Results<unknown[]>): QueryResult {
  return {
    fields: r.fields.map((f) => ({ name: f.name, dataTypeID: f.dataTypeID })),
    rows: r.rows,
    command: r.command,
    // у SELECT affectedRows = 0, поэтому берём число строк
    rowCount: r.affectedRows || r.rows.length,
  };
}

// Обработчик запросов протокола. Живёт внутри worker'а (браузер) или в процессе (node-тесты)
export function createRequestHandler() {
  let pg: PGlite | null = null;

  async function run(req: WorkerRequest): Promise<unknown> {
    if (req.type === 'init') {
      pg = new PGlite(req.dataDir ? { loadDataDir: req.dataDir } : {});
      await pg.waitReady;
      return null;
    }
    if (!pg) throw new Error('База не инициализирована');
    switch (req.type) {
      case 'query':
        return toResult(await pg.query<unknown[]>(req.sql, req.params, { rowMode: 'array' }));
      case 'exec':
        return (await pg.exec(req.sql, { rowMode: 'array' })).map((r) => toResult(r as Results<unknown[]>));
      case 'dump':
        // без checkpoint после загрузки из дампа identity прыгают на ~32 вперёд (WAL логирует последовательности с запасом)
        await pg.exec('checkpoint');
        return pg.dumpDataDir('gzip');
      case 'version':
        return (await pg.query<[string]>('select version()', [], { rowMode: 'array' })).rows[0][0];
    }
  }

  return {
    async handle(req: WorkerRequest): Promise<WorkerResponse> {
      try {
        return { id: req.id, ok: true, value: await run(req) };
      } catch (e) {
        return { id: req.id, ok: false, error: toDbError(e) };
      }
    },
    async close(): Promise<void> {
      await pg?.close();
      pg = null;
    },
  };
}
```

```ts
import { createRpcClient } from './client';
import { createRequestHandler } from './handler';
import type { WorkerResponse } from './protocol';
import type { DbClient } from './types';

// Тот же протокол, но PGlite в текущем процессе. Таймаута нет: wasm блокирует поток, сторож всё равно не сработает
export function createNodeClient(opts: { dataDir?: Blob } = {}): Promise<DbClient> {
  const handler = createRequestHandler();
  let listener: (res: WorkerResponse) => void = () => {};
  return createRpcClient(
    {
      post: (req) => void handler.handle(req).then((res) => listener(res)),
      onMessage: (cb) => {
        listener = cb;
      },
      onError: () => {},
      terminate: () => handler.close(),
    },
    { dataDir: opts.dataDir, timeoutMs: 0, initTimeoutMs: 0 },
  );
}
```

```ts
import { type DatasetId, loadDatasetSql } from '@/features/db/datasets';
import { createNodeClient } from '@/features/db/node-client';
import type { DbClient } from '@/features/db/types';

const dumps = new Map<DatasetId, Promise<Blob>>();

// Снапшот датасета строится один раз на процесс: exec SQL → dump
export function datasetDump(id: DatasetId): Promise<Blob> {
  let dump = dumps.get(id);
  if (!dump) {
    dump = (async () => {
      const db = await createNodeClient();
      try {
        await db.exec(await loadDatasetSql(id));
        return await db.dump();
      } finally {
        await db.close();
      }
    })();
    dumps.set(id, dump);
  }
  return dump;
}

export async function withDataset<T>(id: DatasetId, fn: (db: DbClient) => Promise<T>): Promise<T> {
  const db = await createNodeClient({ dataDir: await datasetDump(id) });
  try {
    return await fn(db);
  } finally {
    await db.close();
  }
}

export async function inPreview<T>(db: DbClient, fn: () => Promise<T>): Promise<T> {
  await db.query('begin');
  try {
    return await fn();
  } finally {
    await db.query('rollback');
  }
}
```

```ts
async function mortalClient(dataDir?: Blob): Promise<DbClient> {

  let dead = false;
  const check = async (sql: string) => {

      await check(sql);
      return real.query(sql, params);

      await check(sql);
      return real.exec(sql);
    },
    dump: () => real.dump(),
    version: () => real.version(),
    close: async () => {
      if (!dead) await real.close();
      dead = true;
    },
  };
}
```

```ts
import { type DatasetId, loadDatasetSql } from './datasets';
import { type DbClient, DbException, type QueryResult, SANDBOX_CRASHED, SANDBOX_TIMEOUT } from './types';

export interface Sandbox {
  readonly status: 'booting' | 'ready' | 'restarting' | 'failed';
  readonly datasetId: DatasetId | null;
  client(): DbClient; // текущий живой клиент
  loadLesson(datasetId: DatasetId, journal: readonly string[]): Promise<void>;
  // BEGIN; fn(client); ROLLBACK: всегда, даже при ошибке. Зависание ловит сторож клиента (VS001).
  // signal: превью устаревшего поколения, которое ещё не начало выполняться, отменяется (AbortError)
  preview<T>(fn: (db: DbClient) => Promise<T>, signal?: AbortSignal): Promise<T>;
  apply(sql: string): Promise<QueryResult[]>; // exec с автокоммитом, в журнал при успехе
  undo(): Promise<void>; // снапшот датасета + журнал без последнего
  reset(): Promise<void>; // снапшот датасета, журнал пуст
  journal(): readonly string[];
  subscribe(listener: (e: SandboxEvent) => void): () => void;
}
export type SandboxEvent =
  | { type: 'status'; status: Sandbox['status'] }
  | { type: 'restarted'; reason: 'timeout' | 'crash' }
  | { type: 'changed' }; // после apply/undo/reset/loadLesson: пора обновить доску

const isDeath = (e: unknown): e is DbException =>
  e instanceof DbException && (e.db.code === SANDBOX_TIMEOUT || e.db.code === SANDBOX_CRASHED);

// id текущей транзакции; null, если она прервана ошибкой (это всё ещё наша транзакция)
async function xactId(db: DbClient): Promise<string | null> {
  try {
    return String((await db.query('select pg_current_xact_id()::text')).rows[0][0]);
  } catch (e) {
    if (e instanceof DbException && e.db.code === '25P02') return null;
    throw e;
  }
}

export function createSandbox(factory: (dataDir?: Blob) => Promise<DbClient>): Sandbox {
  const snapshots = new Map<DatasetId, Blob>();
  const listeners = new Set<(e: SandboxEvent) => void>();
  let status: Sandbox['status'] = 'booting';
  let datasetId: DatasetId | null = null;
  let journal: string[] = [];
  let db: DbClient | null = null;
  let lock: Promise<unknown> = Promise.resolve();

  const emit = (e: SandboxEvent) => {
    for (const l of listeners) l(e);
  };
  const setStatus = (s: Sandbox['status']) => {
    if (s === status) return;
    status = s;
    emit({ type: 'status', status: s });
  };
  const live = (): DbClient => {
    if (!db) throw new DbException({ code: SANDBOX_CRASHED, message: 'Песочница не готова' });
    return db;
  };

  // Операции идут строго по одной: превью, применение и пересборка не перемешиваются
  function exclusive<T>(fn: () => Promise<T>): Promise<T> {
    const run = lock.then(fn);
    lock = run.catch(() => {});
    return run;
  }

  // Новый клиент: снапшот датасета (из кэша или собранный сейчас) + повтор журнала.
  // Запись журнала, которая больше не выполняется, и всё после неё отбрасываются.
  async function rebuild(id: DatasetId, entries: readonly string[]): Promise<void> {
    const old = db;
    db = null;
    await old?.close();
    const cached = snapshots.get(id);
    const next = await factory(cached);
    if (!cached) {
      await next.exec(await loadDatasetSql(id));
      snapshots.set(id, await next.dump());
    }
    const kept: string[] = [];
    for (const sql of entries) {
      try {
        await next.exec(sql);
        kept.push(sql);
      } catch (e) {
        if (isDeath(e)) throw e;
        break;
      }
    }
    db = next;
    datasetId = id;
    journal = kept;
  }

  async function changeTo(entries: readonly string[]): Promise<void> {
    if (!datasetId) throw new Error('Урок не загружен');
    await rebuild(datasetId, entries);
    emit({ type: 'changed' });
  }

  return {
    get status() {
      return status;
    },
    get datasetId() {
      return datasetId;
    },
    client: live,
    journal: () => journal,
    subscribe(listener) {
      listeners.add(listener);
      return () => listeners.delete(listener);
    },

    loadLesson: (id, entries) =>
      exclusive(async () => {
        // тот же датасет и тот же журнал: база уже в нужном состоянии
        if (
          db &&
          id === datasetId &&
          entries.length === journal.length &&
          entries.every((s, i) => s === journal[i])
        )
          return;
        setStatus('booting');
        try {
          await rebuild(id, entries);
        } catch (e) {
          setStatus('failed');
          throw e;
        }
        setStatus('ready');
        emit({ type: 'changed' });
      }),

    preview: (fn, signal) =>
      exclusive(async () => {
        signal?.throwIfAborted();
        const client = live();
        await client.query('begin');
        const started = await xactId(client);
        const outcome = await fn(client).then(
          (value) => ({ ok: true as const, value }),
          (error: unknown) => ({ ok: false as const, error }),
        );
        if (!outcome.ok && isDeath(outcome.error)) throw outcome.error;
        const now = await xactId(client);
        await client.query('rollback');
        // внутри превью выполнился COMMIT: база изменилась, возвращаем состояние журнала
        if (now !== null && now !== started) await changeTo(journal);
        if (!outcome.ok) throw outcome.error;
        return outcome.value;
      }),

    apply: (sql) =>
      exclusive(async () => {
        const res = await live().exec(sql);
        journal = [...journal, sql];
        emit({ type: 'changed' });
        return res;
      }),

    undo: () => exclusive(() => (journal.length ? changeTo(journal.slice(0, -1)) : Promise.resolve())),
    reset: () => exclusive(() => changeTo([])),
  };
}
```

```ts
        sampleCtids = sampleRows.map((_, i) => `row:${i}`);
      }

    tables.push({
      id: idOf(oid) as string,
      schema: schemaName(schema),
      name,
      kind,
      columns: columns
        .filter((c) => c[0] === oid)
        .map(([, col, type, nullable, def, identity, generated]) => {
          const fk = own.find(([, , t, cols]) => t === 'f' && cols.includes(col));
          const target = fk && byOid.get(fk[4]);
          return {
            name: col,
            type,
            nullable,
            default: def,
            isPk: has('p', col),
            isUnique: has('u', col, true),
            isGenerated: generated !== '',
            identity: identity === 'a' ? 'always' : identity === 'd' ? 'by default' : null,
            checks: own.filter(([, , t, cols]) => t === 'c' && cols.includes(col)).map((c) => c[8]),
            fk: fk && target ? { ...target, column: fk[5][fk[3].indexOf(col)] } : null,
          };
        }),
      rowCount,
      sampleRows,
      sampleCtids,
      indexes: indexes
        .filter((i) => i[0] === oid)
        .map(([, n, definition, unique, primary]) => ({ name: n, definition, unique, primary })),
      comment,
    });

      onUpdate: FK_ACTIONS[onUpdate],

    schemas,
    tables,
    fks,
    sequences: sequences.map(([schema, name, lastValue]) => ({
      schema: schemaName(schema),
      name,
      lastValue,
    })),
  };
}
```

```ts
import type { SchemaSnapshot, TableInfo } from '@/features/db/introspect';
import { type DbError, SANDBOX_CRASHED, SANDBOX_TIMEOUT } from '@/features/db/types';

export interface ErrorExplanation {
  title: string;
  body: string;
  suggestion?: string;
  highlight: { tableIds: string[]; columns: string[] };
}
export interface ErrorContext {
  sql: string;
  schema: SchemaSnapshot | null;
}
type Entry = (err: DbError, ctx: ErrorContext) => ErrorExplanation;

const none = { tableIds: [], columns: [] };

// Первое имя в кавычках из текста ошибки: relation "books" → books
const quoted = (message: string) => /"([^"]+)"/.exec(message)?.[1] ?? '';

function distance(a: string, b: string): number {
  const row = Array.from({ length: b.length + 1 }, (_, i) => i);
  for (let i = 1; i <= a.length; i++) {
    let prev = row[0];
    row[0] = i;
    for (let j = 1; j <= b.length; j++) {
      const cur = row[j];
      row[j] = Math.min(row[j] + 1, row[j - 1] + 1, prev + (a[i - 1] === b[j - 1] ? 0 : 1));
      prev = cur;
    }
  }
  return row[b.length];
}

// Ближайшее по написанию имя: не дальше 2 правок и не больше половины длины
function closest(name: string, candidates: string[]): string | undefined {
  let best: string | undefined;
  let bestDistance = Math.min(2, Math.floor(name.length / 2)) + 1;
  for (const c of new Set(candidates)) {
    const d = distance(name.toLowerCase(), c.toLowerCase());
    if (d > 0 && d < bestDistance) {
      best = c;
      bestDistance = d;
    }
  }
  return best;
}

// Таблицы, имя которых встречается в тексте запроса отдельным словом
function tablesInSql(ctx: ErrorContext): TableInfo[] {
  const words = new Set(ctx.sql.toLowerCase().match(/[a-z_][a-z0-9_]*/g) ?? []);
  return ctx.schema?.tables.filter((t) => words.has(t.name.toLowerCase())) ?? [];
}

  `${t.schema ?? 'public'}.${t.table}.${column}`;

  const m = /Key \(([^)]*)\)=\((.*)\)/.exec(detail);
  return m ? { columns: m[1].split(', '), values: m[2] } : null;
}
```

```tsx
import { createContext, type ReactNode, useContext, useEffect, useState } from 'react';
import { createWorkerClient } from './client';
import { createSandbox, type Sandbox } from './sandbox';

interface SandboxState {
  sandbox: Sandbox | null;
  status: Sandbox['status'];
  version: string | null;
}

const SandboxContext = createContext<SandboxState>({ sandbox: null, status: 'booting', version: null });

// Песочница создаётся после первого рендера оболочки. Worker с PGlite (отдельный чанк)
// стартует только на первом loadLesson, поэтому теория видна сразу.
export function SandboxProvider({ children }: { children: ReactNode }) {
  const [state, setState] = useState<SandboxState>({ sandbox: null, status: 'booting', version: null });

  useEffect(() => {
    const sandbox = createSandbox((dataDir) => createWorkerClient({ dataDir }));
    const off = sandbox.subscribe((e) => {
      if (e.type !== 'status') return;
      setState((s) => ({ ...s, status: e.status }));
      if (e.status === 'ready') {
        sandbox
          .client()
          .version()
          .then(
            (version) => setState((s) => ({ ...s, version })),
            () => {},
          );
      }
    });
    setState({ sandbox, status: sandbox.status, version: null });
    // ручка для e2e и отладки в консоли
    if (import.meta.env.DEV) (window as { __vsSandbox?: Sandbox }).__vsSandbox = sandbox;
    // worker не закрываем: провайдер живёт всё время работы приложения, а в StrictMode
    // первый экземпляр песочницы снимается раньше, чем кто-то успевает вызвать loadLesson
    return off;
  }, []);

  return <SandboxContext.Provider value={state}>{children}</SandboxContext.Provider>;
}

export function useSandbox(): SandboxState {
  return useContext(SandboxContext);
}
```

```ts
import { useEffect } from 'react';
import { toast } from 'sonner';
import { useLessonStore } from '@/stores/lesson';
import type { DatasetId } from './datasets';
import type { Sandbox } from './sandbox';

export const RESTART_MESSAGES = {
  timeout: 'Запрос выполнялся дольше 3 секунд. Песочница перезапущена, твои изменения восстановлены.',
  crash: 'Песочница перезапущена, твои изменения восстановлены.',
} as const;

// Связывает песочницу с текущим уроком: поднимает датасет с сохранённым журналом,
// пишет журнал обратно в localStorage после каждого изменения и показывает тост после перезапуска.
export function useLessonSandbox(
  sandbox: Sandbox | null,
  lessonId: string | undefined,
  datasetId: DatasetId | undefined,
) {
  useEffect(() => {
    if (!sandbox || !lessonId || !datasetId) return;
    // пока наш loadLesson не завершился, события относятся к прошлому уроку
    let loaded = false;
    const saveJournal = () => useLessonStore.getState().setJournal(lessonId, [...sandbox.journal()]);
    const off = sandbox.subscribe((e) => {
      if (e.type === 'restarted') toast.warning(RESTART_MESSAGES[e.reason]);
      if (e.type === 'changed' && loaded) saveJournal();
    });
    const saved = useLessonStore.getState().byId[lessonId]?.journal ?? [];
    sandbox.loadLesson(datasetId, saved).then(
      () => {
        loaded = true;
        saveJournal(); // журнал мог обрезаться, если запись больше не выполняется
      },
      () => toast.error('Не удалось поднять Postgres. Обнови страницу.'),
    );
    return off;
  }, [sandbox, lessonId, datasetId]);
}
```

### Task 11: Превью не сдвигает последовательности (P2.16)

Последовательности в Postgres не откатываются: каждое превью `INSERT` с identity сдвигает счётчик, и после «Применить» новый автор получает id 9 вместо 7 (проверено 2026-10-08: два превью без обхода дают 9).
```ts
// Последовательности не откатываются вместе с транзакцией: снимаем их до превью и возвращаем после
const SEQ_STATE = 'select seqrelid::regclass::text, pg_sequence_last_value(seqrelid)::text from pg_sequence';

async function sequenceState(db: DbClient): Promise<Map<string, string | null>> {
  const { rows } = await db.query(SEQ_STATE);
  return new Map(rows.map((r) => [String(r[0]), r[1] === null ? null : String(r[1])]));
}

async function restoreSequences(db: DbClient, before: Map<string, string | null>): Promise<void> {
  const after = await sequenceState(db);
  for (const [seq, value] of before) {
    if (after.get(seq) === value) continue;
    // null: последовательность ещё ни разу не выдавала значение
    if (value === null) await db.query('select setval($1::regclass, 1, false)', [seq]);
    else await db.query('select setval($1::regclass, $2::bigint, true)', [seq, value]);
  }
}
```

В `preview` снять состояние до `begin` и вернуть после `rollback` (последовательности, созданные внутри превью, после отката исчезают и в `before` их нет):

```ts
        const client = live();
        const sequences = await sequenceState(client);
        await client.query('begin');
```

```ts
        await client.query('rollback');
        await restoreSequences(client, sequences);
```

Ограничение: `setval(seq, 1, false)` для ни разу не вызванной последовательности предполагает `START WITH 1`. Для учебных датасетов это так; последовательность с другим стартом, созданная уроком через «Применить» и ещё не вызванная, после превью начнёт с 1. ponytail: при необходимости читать `seqstart` из `pg_sequence`.
