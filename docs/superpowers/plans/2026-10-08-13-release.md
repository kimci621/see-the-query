> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** открыть сайт по публичному адресу: хостинг статики с правильным кэшем WASM, деплой из CI по тегу, SEO/мета/OG, страница «О проекте» с лицензиями, аналитика без кук, вычитка всех текстов на оригинальность, финальные аудиты доступности (WCAG AA) и производительности (Lighthouse ≥90 по производительности оболочки, бюджеты спеки 9). Критерий фазы из трекера: «сайт открыт по публичному адресу, тексты прошли вычитку на оригинальность, Lighthouse ≥90».

**Architecture:** бэкенда нет, публикуется статика `dist/` из `vite build`. **Tech Stack:** без новых runtime-зависимостей. devDependency `@axe-core/playwright` (e2e-аудит доступности, вносится через контракты). Lighthouse запускается через `pnpm dlx` и в `package.json` не попадает. Хостинг: Cloudflare Pages (по умолчанию, см. задачу 5) или Vercel.

**Spec:** `docs/superpowers/specs/2026-10-08-visual-sql-design.md`, разделы 9 (бюджеты производительности), 10 (доступность), 11 (фаза 13), 12 (риск «Авторское право»), 14 (открытые вопросы: название, английский язык). Контракты: `docs/superpowers/plans/2026-10-08-00-contracts.md`. Факты по весам: `docs/spikes.md` (pglite.wasm 9.9 МБ / 3.5 МБ gzip, pglite.data 6.1 МБ, initdb.wasm 0.4 МБ, libpg-query.wasm 1.7 МБ / 345 КБ gzip; снапшоты живут в памяти, по сети не ходят).

## Review Focus

1. **Кэш против фиксированных имён.** `libpg-query.wasm` лежит в корне `dist/` без хеша: если отдать его с `immutable`, новые версии никогда не доедут. Задача 5 обязана начинаться с инвентаризации `dist/` (какие файлы хешированы) и писать заголовки по факту, а не вслепую.
2. **Вычитка на оригинальность.** Скрипт шинглов ловит дословные фразы, но не пересказ и не чужие аналогии. Финальное слово за ручным сравнением каждого урока с `conspectus.md` курса (задача 4). Порог 6 слов отсекает терминологию (SQL-термины совпадают законно), но это же значит: чистый прогон скрипта не закрывает P13.2 сам по себе.
3. **Lighthouse ≥90 на оболочке.** PGlite (~16 МБ ассетов), парсер и CodeMirror грузятся лениво и не должны попасть в критический путь первой отрисовки. Главные угрозы баллам: аналитика-скрипт и шрифты. Порог проверяется на прод-сборке, не на dev.
4. **SPA-мета.** Соцсети не исполняют JS: пер-урок OG-картинки и описания они увидят только через prerender, которого в стеке нет. План честно закрывает P13.5 как: статический OG для сайта + JS-мета для браузера и исполняющих JS краулеров (Google). Prerender не строим (см. «Отклонения»).
5. **Деплой и smoke.** Первый деплой должен пройти ручную проверку заголовков и ассетов через `curl` до закрытия P13.3/P13.4: workflow зелёный не значит, что заголовки кэша доехали.

## Задача 3. Скрипт вычитки на оригинальность

Ищет дословные совпадения фраз между нашим контентом (`content/lessons`, `content/tasks`) и текстами курса. SQL-блоки и MDX-теги выкидываются: синтаксис и компоненты общие, сравниваем прозу. Курс лежит локально (CLAUDE.md), в CI его нет - это рабочий инструмент вычитки, а не тест CI.

**Files:**
- Create: `scripts/originality.mjs`

**Interfaces:** CLI: `node scripts/originality.mjs [путь к топикам курса]`. Exit 0 - чисто, 1 - найдены совпадения, 2 - папка курса не найдена.

- [ ] **Шаг 1. Код.**
  ```js
  #!/usr/bin/env node
  // Вычитка на оригинальность: совпадения фраз из нашего контента с текстами курса.
  // Порог - 6 слов подряд: короче сплошная терминология, длиннее пропускает пересказ.
  // Финальное слово за ручной вычиткой (задача 4): скрипт ловит только дословность.
  import { readdirSync, readFileSync, statSync } from 'node:fs';
  import { homedir } from 'node:os';
  import { join } from 'node:path';

  const COURSE_DIR =
    process.argv[2] ?? join(homedir(), 'Projects/digitaliziruy!/synopsis/topics');
  const TARGETS = ['content/lessons', 'content/tasks'];
  const SHINGLE = 6;

  function walk(dir, acc = []) {
    for (const entry of readdirSync(dir)) {
      const p = join(dir, entry);
      if (statSync(p).isDirectory()) walk(p, acc);
      else if (/\.(mdx|md)$/.test(entry)) acc.push(p);
    }
    return acc;
  }

  // SQL-блоки и mdx-разметку выкидываем: сравниваем только прозу
  function words(text) {
    return text
      .replace(/```[\s\S]*?```/g, ' ')
      .replace(/<\/?[A-Za-z][^>]*>/g, ' ')
      .replace(/[^\p{L}\p{N}]+/gu, ' ')
      .toLowerCase()
      .split(/\s+/)
      .filter(Boolean);
  }

  const key = (w) => w.join(' ');

  const courseIndex = new Set();
  for (const f of walk(COURSE_DIR)) {
    const w = words(readFileSync(f, 'utf8'));
    for (let i = 0; i + SHINGLE <= w.length; i++) {
      courseIndex.add(key(w.slice(i, i + SHINGLE)));
    }
  }
  if (courseIndex.size === 0) {
    console.error(`Курс не найден или пуст: ${COURSE_DIR}`);
    process.exit(2);
  }

  let found = 0;
  for (const dir of TARGETS) {
    for (const file of walk(dir)) {
      const w = words(readFileSync(file, 'utf8'));
      const hit = new Array(w.length).fill(false);
      for (let i = 0; i + SHINGLE <= w.length; i++) {
        if (courseIndex.has(key(w.slice(i, i + SHINGLE)))) {
          for (let j = i; j < i + SHINGLE; j++) hit[j] = true;
        }
      }
      // подряд покрытые слова склеиваем в цитаты
      let i = 0;
      while (i < w.length) {
        if (!hit[i]) { i++; continue; }
        let j = i;
        while (j < w.length && hit[j]) j++;
        console.log(`${file}: «${w.slice(i, j).join(' ')}»`);
        found++;
        i = j;
      }
    }
  }
  console.log(found === 0 ? 'OK: заимствований не найдено' : `Найдено совпадений: ${found}`);
  process.exit(found === 0 ? 0 : 1);
  ```
- [ ] **Шаг 2. Самотест на контрольной вставке.** Взять один абзац из любого `conspectus.md` курса, записать его во временный файл `content/lessons/99-selftest/00-check.mdx`.

  ```js
  #!/usr/bin/env node
  // Генерирует sitemap.xml из frontmatter id уроков. Домен - из src/app/site.ts.
  // Использование: node scripts/gen-sitemap.mjs [путь вывода] (по умолчанию dist/sitemap.xml,
  // вызывается в CI после build; локально - pnpm sitemap в public/).
  import { mkdirSync, readdirSync, readFileSync, statSync, writeFileSync } from 'node:fs';
  import { dirname, join } from 'node:path';

  const out = process.argv[2] ?? 'public/sitemap.xml';
  const site = readFileSync('src/app/site.ts', 'utf8');
  const origin = site.match(/url:\s*'([^']+)'/)?.[1];
  if (!origin) throw new Error('не найден SITE.url в src/app/site.ts');

  function walk(dir, acc = []) {
    for (const entry of readdirSync(dir)) {
      const p = join(dir, entry);
      if (statSync(p).isDirectory()) walk(p, acc);
      else if (/\.mdx$/.test(entry)) acc.push(p);
    }
    return acc;
  }

  const urls = [`${origin}/`, `${origin}/about`];
  for (const f of walk('content/lessons')) {
    const id = readFileSync(f, 'utf8').match(/^id:\s*['"]?([^\s'"]+)/m)?.[1];
    if (id) urls.push(`${origin}/l/${id}`);
  }
  urls.sort();

  const today = new Date().toISOString().slice(0, 10);
  const xml = `<?xml version="1.0" encoding="UTF-8"?>
  <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  ${urls.map((u) => `  <url><loc>${u}</loc><lastmod>${today}</lastmod></url>`).join('\n')}
  </urlset>
  `;
  mkdirSync(dirname(out), { recursive: true });
  writeFileSync(out, xml);
  console.log(`sitemap: ${urls.length} URL -> ${out}`);
  ```

  ```js
  // Собирает лицензии зависимостей (pnpm licenses list --json) в licenses.json.
  // Обновлять при смене зависимостей: pnpm licenses.
  import { execFileSync } from 'node:child_process';

  const list = [...new Map(entries.map((e) => [`${e.name}@${e.license}`, e])).values()]
  ```
