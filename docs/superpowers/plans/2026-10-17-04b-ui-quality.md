# Ф4б «Качество UI»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрыть все P1 и P2 из `/impeccable critique` (22/40) и `/impeccable audit` (11/20) от 2026-10-17 до начала Ф5, чтобы оверлей Ф6 строился на читаемой доске, честном цикле ошибки, рабочей тёмной теме и токенах, проходящих AA.

**Architecture:** Точечные правки существующих модулей `editor`, `results`, `board`, `shell`, `errors` и токенов `src/index.css`, без новых модулей и зависимостей. Новый токен `--touched` («это трогает твой запрос») заменяет `--primary` во всех подсветках запроса, а палитра `--sql-*` объединяет подсветку SQL в теории (shiki) и редакторе (CodeMirror). Сторонние виджеты (React Flow, CodeMirror, автокомплит) переводятся на токены проекта. Каждая задача: тест, который падает, правка, зелёный `pnpm check`, коммит.

**Tech Stack:** React 19, TypeScript strict, Tailwind v4 + shadcn, `@xyflow/react@12.12.0` (`colorMode`, `ariaLabelConfig`), `@uiw/react-codemirror@4.25.12` (`theme="none"`, `indentWithTab`), `@codemirror/lint@6.9.7` (`setDiagnostics` сам ставит lint-состояние), `shiki@4.5.0` (`createCssVariablesTheme`), zustand, sonner, Vitest (node + dom), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-08-visual-sql-design.md`, разделы 3.4, 3.6, 3.8, 3.9, 3.10, 3.11, 5.12, 5.14, 10. Источник находок: `.impeccable/critique/2026-10-17T08-21-52Z__src.md` и отчёт audit в истории сессии (пересказан в задачах ниже).

## Global Constraints

- Спека важнее кода. Правки спеки 3.4, 3.8, 3.9, 3.10, 3.11 согласованы пользователем 2026-10-17 и вносятся задачей 1 до кода.
- Перед пунктом трекера ⬜ → 🔄 с датой (`date +%F`), после проверки 🔄 → ✅ с датой. Трекер коммитится в последнем коммите пункта.
- Коммит только при зелёном `pnpm check`. Conventional Commits на русском, файлы явными путями, последняя строка `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Базовая доска не анимируется (инвариант 2). Семантический зум и подсветки делаются CSS-классом или data-атрибутом контейнера, без пересборки нод.
- Новые зависимости запрещены. Нужен диалог подтверждения: берём существующий `src/components/ui/dialog.tsx`.
- `src/components/ui/*` правим только при реальной нужде. Фокус-кольцо чиним токеном `--ring` и правилом в `src/index.css`, не vendor-файлами.
- Тексты интерфейса на русском, комментарии на русском, без длинных тире, без `any` и `!`.
- Контраст по WCAG AA в обеих темах (спека 10): текст ≥ 4.5:1, нетекстовые индикаторы (кольцо фокуса, рамка `touched`) ≥ 3:1.
- `features/board` не знает про запросы, `features/tracer` не трогаем.

## Review Focus

1. Тема переключается на лету (светлая → тёмная без перезагрузки): React Flow и CodeMirror должны перекраситься сразу. Тест в задаче 5 переключает тему после монтирования.
2. Урок открывается до загрузки WASM-парсера (холодный старт): «Применить» и «Применить всё» должны ожить без правки текста. Тест в задаче 2.
3. Подчёркивание ошибки живёт дольше секунды: линтер CodeMirror не должен затирать программные диагностики через 750 мс. Тест в задаче 3 ждёт 1200 мс.
4. Широкий результат (`select * from book`, панель уже суммы колонок) после горизонтальной прокрутки: значения стоят под своими заголовками. Тест в задаче 4.
5. Кириллица перед местом ошибки при правке по подсказке («Может, title?»): замена попадает ровно в слово ошибки. Тест в задаче 9 ставит кириллицу в строковый литерал до ошибочной колонки.
