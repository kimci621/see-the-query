# Ф4 «Редактор»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Правая колонка получает живой SQL-редактор: CodeMirror 6 с диалектом PostgreSQL и темой приложения, автодополнение по текущей схеме, debounce 250 мс с отменой устаревших поколений, оператор под курсором, волнистое подчёркивание ошибок парсинга и Postgres, панель результата («Результат»/«Сообщения»), кнопки «Превью», «Применить ⌘⏎», «Применить всё», «Отменить ⌘Z», «Сброс», связь курсор ↔ клауз ↔ доска (фокус по FROM, подсветка колонок по наведению). Критерий фазы из трекера: пишешь запрос, через ≤300 мс после паузы видишь результат и фокус на доске, ошибки подчёркнуты и объяснены.

**Architecture:** Трассировщика ещё нет (Ф5), поэтому в Ф4 сцена всегда «только итог»: `useLiveTrace` парсит текст, берёт оператор под курсором, выполняет его в `sandbox.preview` и кладёт в `useSceneStore` объект `Trace` с `mode: 'final-only'`, пустыми стадиями и `touched` из `relationsOf`. Панель результата читает `trace.result`, вкладка «Сообщения» прогоняет `trace.error` через словарь Ф2, доска фокусируется по `trace.touched`. Чистая логика (offsets, parser, statements, relations, clauses, touched, diagnostics, hover, completion) живёт в `features/sql` и `features/editor` без React и тестируется в node-проекте Vitest. CodeMirror грузится лениво через `React.lazy`, WASM libpg-query выпускается плагином `libpgQueryWasm()` (обход из Ф0, код сверен с `spikes/vite.config.ts`). Ф5 подменит построение трейса на `traceStatement`, не меняя потребителей стора.

**Tech Stack:** TypeScript strict, Vite 8, React 19.3, `libpg-query@18.1.5` + `@pgsql/types` (типы AST), `@uiw/react-codemirror@4.25.12`, `@codemirror/lang-sql@6.10.0` (диалект PostgreSQL, встроенное автодополнение по схеме), `@codemirror/{view,state,language,commands,lint}` 6.x, `@lezer/highlight`, `@tanstack/react-virtual@3.14.13`, zustand 5, Tailwind v4 + shadcn (`badge`, `button`, `kbd`, `skeleton`, `tabs`), sonner, Vitest 5 (node + dom), Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-08-visual-sql-design.md`, разделы 3.6 (редактор), 3.8 (панель результата), 3.9 (превью и применить), 3.10 (горячие клавиши), 5.3 (поток данных), 5.5 (парсер), 5.12 (состояния интерфейса), 5.14 (ошибки). Контракты: `docs/superpowers/plans/2026-10-08-00-contracts.md`, разделы 1 (версии, факты libpg-query, обход WASM), 3 (раскладка), 4 (`Sandbox`, `SandboxProvider`, `DbError`, `DbException`), 5 (sql-модуль: контракты всех функций фазы), 7 (`scene.ts`, `editor.ts`), 11 (`explainError`).

## Review Focus

1. **Позиции после кириллицы.** `parseSql`, `relationsOf`, `clauseRanges` обязаны давать символьные позиции, совпадающие с координатами CodeMirror (UTF-16). Риски: байтовые позиции libpg-query, пропуск `stmt_location` при 0, кавычки. Тесты с `'Привет'` перед колонкой и алиасом `"Книга"` перед WHERE (задачи 2, 3, 4), hover на кириллическом запросе (задача 11).
2. **Debounce и поколения.** Быстрый набор не порождает гонку: результат старого поколения не может перезаписать новый, ошибка парсинга гасит сцену без мигания, перевод курсора в другой оператор перевыбирает превью. Тесты `useLiveTrace` на fake timers (задача 8).
3. **Превью не меняет базу, «Применить» меняет.** `apply` только по кнопке/`⌘⏎`, превью всегда внутри `sandbox.preview`; после `apply/undo/reset` превью перевыполняется по событию `changed`. Тесты тулбара (задача 10) и e2e (задача 12).
4. **Диагностики и сообщения.** Ошибка парсинга подчёркнута волной на слове под позицией, ошибка Postgres - на слове по `position` (сдвиг от начала оператора до абсолютной позиции редактора), оригинальный текст всегда рядом с человеческим объяснением. Тесты `diagnostics` (задача 8), `MessagesList` (задача 9), e2e (задача 12).
5. **Производительность.** Парсинг в эффектах выполняется 1-3 раза на нажатие (эффект клауза, hover, превью), каждый < 1 мс по спайкам Ф0 - допустимо; CodeMirror грузится лениво, оболочка его не ждёт (спека 5.12). Проверка: `pnpm build` и первый рендер в e2e.

- [ ] **Step 1: WASM-плагин в `vite.config.ts`**

Обход из Ф0 (код сверен с `spikes/vite.config.ts`): emscripten в собранном бандле запрашивает `/libpg-query.wasm` от корня сайта, а Vite файл не выпускает. В `vite.config.ts` добавить импорты:

```ts

import { dirname, join } from 'node:path';
```

и перед `export default defineConfig`:

```ts
// libpg-query (emscripten) ищет libpg-query.wasm рядом со своим чанком, а Vite его не выпускает.
// В собранном бандле он запрашивает /libpg-query.wasm от корня сайта: кладём файл туда.
function libpgQueryWasm(): Plugin {
  const require = createRequire(import.meta.url);
  const file = join(dirname(require.resolve('libpg-query')), 'libpg-query.wasm');
  return {
```

```ts
// Позиции libpg-query - байты UTF-8, а CodeMirror и JS-строки - кодовые единицы UTF-16.

export function byteToChar(text: string, byteOffset: number): number {
  let bytes = 0;
  for (let i = 0; i < text.length; i++) {
    if (bytes >= byteOffset) return i;
    const code = text.charCodeAt(i);
    if (code < 0x80) bytes += 1;
    else if (code < 0x800) bytes += 2;
    else if (code >= 0xd800 && code <= 0xdbff) bytes += 4; // сурогатная пара: два code unit = 4 байта
    else bytes += 3;
  }
  return text.length;
}

export function charToByte(text: string, charOffset: number): number {
  let bytes = 0;
  const end = Math.min(charOffset, text.length);
  for (let i = 0; i < end; i++) {
    const code = text.charCodeAt(i);
    if (code < 0x80) bytes += 1;
    else if (code < 0x800) bytes += 2;
    else if (code >= 0xd800 && code <= 0xdbff) {
      bytes += 4;
      i++; // второй code unit пары не считать отдельно
    } else bytes += 3;
  }
  return bytes;
}
```

```ts
import type { Node, RawStmt } from '@pgsql/types';
import { loadModule, parseSync } from 'libpg-query';
import { byteToChar, charToByte } from './offsets';
import type { ParseOutcome, ParsedStatement, StatementKind } from './types';

let loadPromise: Promise<void> | null = null;

// Идемпотентная загрузка WASM-парсера: вызывать можно много раз
export function initParser(): Promise<void> {
  loadPromise ??= loadModule().then(() => undefined);
  return loadPromise;
}

// Разбор текста редактора на операторы. Позиции libpg-query в байтах UTF-8,
// переводим в символьные и обрезаем ';' и хвостовые пробелы из stmt_len.
export function parseSql(text: string): ParseOutcome {
  let raw: { stmts: RawStmt[] };
  try {
    raw = parseSync(text);
  } catch (e) {
    return { ok: false, error: toParseError(e, text) };
  }
  const textBytes = charToByte(text, text.length);
  const statements = raw.stmts.map((raw, index): ParsedStatement => {
    const byteFrom = raw.stmt_location ?? 0; // поле опускается, когда равно 0
    const byteTo = raw.stmt_len != null ? byteFrom + raw.stmt_len : textBytes;
    const from = byteToChar(text, byteFrom);
    const stmtText = text.slice(from, byteToChar(text, Math.min(byteTo, textBytes))).replace(/;\s*$/, '').trimEnd();
    return { index, from, to: from + stmtText.length, byteFrom, text: stmtText, ast: raw.stmt, kind: kindOf(raw.stmt) };
  });
  return { ok: true, statements };
}

// Узел RawStmt.stmt - объект с единственным ключом-типом
function kindOf(node: Node): StatementKind {
  const key = Object.keys(node as Record<string, unknown>)[0] ?? '';
  if (key === 'SelectStmt') return 'select';
  if (key === 'InsertStmt') return 'insert';
  if (key === 'UpdateStmt') return 'update';
  if (key === 'DeleteStmt') return 'delete';
  if (key === 'MergeStmt') return 'merge';
  if (key === 'TransactionStmt') return 'tcl';
  if (/^(Create|Alter|Drop|Truncate|Rename|Comment|Refresh|Lock|Check|Cluster)/.test(key)) return 'ddl';
  return 'other';
}

interface SqlErrorLike {
  message?: string;
  sqlDetails?: { cursorPosition?: number };
}

// SqlError libpg-query: байтовая курсорная позиция в sqlDetails.cursorPosition
function toParseError(e: unknown, text: string): { message: string; position: number } {
  const err = (e ?? {}) as SqlErrorLike;
  const byte = typeof err.sqlDetails?.cursorPosition === 'number' ? err.sqlDetails.cursorPosition : 0;
  return { message: err.message ?? String(e), position: byteToChar(text, byte) };
}
```

```ts
import type { ParsedStatement } from './types';

// Оператор под курсором: последний, начавшийся не позже курсора.
// Курсор в ';' или комментарии между операторами относится к ближайшему слева (как в DataGrip).
export function statementAt(stmts: ParsedStatement[], cursor: number): ParsedStatement | null {
  let best: ParsedStatement | null = null;
  for (const s of stmts) {
    if (s.from > cursor) break;
    best = s;
    if (cursor <= s.to) return s;
  }
  return best;
}
```

```ts
import { byteToChar } from './offsets';
import type { ColumnRef, ParsedStatement, RangeRef, Relations } from './types';

// Таблицы и колонки оператора: рекурсивный обход AST, узлы RangeVar и ColumnRef.
// Рекурсивный обход устойчив к разным видам операторов (select/insert/update/delete),
// колонки подзапросов собираются тоже - это упоминаемые объекты.
export function relationsOf(stmt: ParsedStatement): Relations {
  const tables: RangeRef[] = [];
  const columns: ColumnRef[] = [];
  const seen = new Set<string>();

  walk(stmt.ast, (key, value) => {
    if (key === 'RangeVar') {
      const name = value.relname;
      if (typeof name !== 'string' || seen.has(`t:${name}`)) return;
      seen.add(`t:${name}`);
      const schema = typeof value.schemaname === 'string' ? value.schemaname : null;
      const alias = typeof value.alias?.aliasname === 'string' ? value.alias.aliasname : null;
      // location узлов абсолютны (байты полного текста): переводим в относительные оператора
      const from = typeof value.location === 'number' ? byteToChar(stmt.text, value.location - stmt.byteFrom) : 0;
      const length = (schema != null ? `${schema}.${name}` : name).length;
      tables.push({ schema, name, alias, from: stmt.from + from, to: stmt.from + from + length });
    } else {
      const fields = Array.isArray(value.fields) ? value.fields : [];
      const names = fields.map((f) => {
        const field = f as Record<string, { sval?: string }>;
        if ('String' in field) return field.String?.sval ?? '';
        if ('A_Star' in field) return '*';
        return '';
      });
      if (names.length === 0 || names.some((n) => n === '')) return;
      if (typeof value.location !== 'number') return;
      const name = names[names.length - 1] ?? '';
      const qualifier = names.length >= 2 ? names[0] : null;
      const from = stmt.from + byteToChar(stmt.text, value.location - stmt.byteFrom);
      const to = from + refLength(stmt.text, value.location - stmt.byteFrom, name);
      const id = `c:${from}:${name}`;
      if (seen.has(id)) return;
      seen.add(id);
      columns.push({ qualifier, name, from, to });
    }
  });

  return { tables, columns };
}

// Длина текста ссылки колонки: квалификатор, точки и имя (звёздочка тоже).
// Пробелы вокруг '.' в SQL допустимы, поэтому меряем по тексту, а не по числу полей.
function refLength(text: string, byteOffset: number, name: string): number {
  const from = byteToChar(text, byteOffset);
  const m = /^(?:[A-Za-z_$][\w$]*\s*\.\s*)*(?:[A-Za-z_$][\w$]*|\*)/.exec(text.slice(from));
  return m ? m[0].length : name.length;
}

function walk(node: unknown, visit: (key: string, value: Record<string, unknown>) => void): void {
  if (Array.isArray(node)) {
    for (const item of node) walk(item, visit);
    return;
  }
  if (node === null || typeof node !== 'object') return;
  for (const [key, value] of Object.entries(node)) {
    if (value === null || typeof value !== 'object') continue;
    if (key === 'RangeVar' || key === 'ColumnRef') visit(key, value as Record<string, unknown>);
    walk(value, visit);
  }
}
```

```ts
import { byteToChar, charToByte } from './offsets';
import type { ClauseName, ClauseRange, ParsedStatement } from './types';

// Диапазоны клаузов: начало - location первого узла клауза, конец - начало следующего клауза
// по порядку записи или конец оператора (спека 5.5). Позиции - в полном тексте редактора.
// Допущение: курсор на ключевых словах (ORDER, GROUP), стоящих до первого узла клауза,
// относится к предыдущему клаузу - для связи курсор <-> стадия это достаточно.
export function clauseRanges(stmt: ParsedStatement): ClauseRange[] {
  const stmtBytes = charToByte(stmt.text, stmt.text.length);
  const starts: Array<{ clause: ClauseName; byte: number }> = [];
  const ast = stmt.ast as Record<string, unknown>;

  const byteFrom = stmt.byteFrom;
  if ('SelectStmt' in ast) {
    const sel = (ast.SelectStmt ?? {}) as Record<string, unknown>;
    pushIf(starts, 'with', loc(sel.withClause), byteFrom);
    pushIf(starts, 'select', loc(sel.targetList), byteFrom);
    pushIf(starts, 'from', loc(sel.fromClause), byteFrom);
    pushIf(starts, 'where', loc(sel.whereClause), byteFrom);
    pushIf(starts, 'group', loc(sel.groupClause), byteFrom);
    pushIf(starts, 'having', loc(sel.havingClause), byteFrom);
    pushIf(starts, 'window', loc(sel.windowClause), byteFrom);
    pushIf(starts, 'order', loc(sel.sortClause), byteFrom);
    pushIf(starts, 'limit', loc(sel.limitCount), byteFrom);
    pushIf(starts, 'offset', loc(sel.limitOffset), byteFrom);
    pushIf(starts, 'values', loc(sel.valuesLists), byteFrom);
  }
  if ('InsertStmt' in ast) {
    const ins = (ast.InsertStmt ?? {}) as Record<string, unknown>;
    const inner = (ins.selectStmt ?? {}) as Record<string, unknown>;
    pushIf(starts, 'with', loc(ins.withClause), byteFrom);
    pushIf(starts, 'into', loc(ins.relation), byteFrom);
    pushIf(starts, 'select', loc(inner.targetList), byteFrom);
    pushIf(starts, 'values', loc(inner.valuesLists), byteFrom);
    const conflict = (ins.onConflictClause ?? null) as Record<string, unknown> | null;
    pushIf(starts, 'on_conflict', loc(conflict?.arbiterElems) ?? loc(conflict), byteFrom);
    pushIf(starts, 'returning', loc(ins.returningList), byteFrom);
  }
  if ('UpdateStmt' in ast) {
    const upd = (ast.UpdateStmt ?? {}) as Record<string, unknown>;
    pushIf(starts, 'with', loc(upd.withClause), byteFrom);
    pushIf(starts, 'set', loc(upd.targetList), byteFrom);
    pushIf(starts, 'from', loc(upd.fromClause), byteFrom);
    pushIf(starts, 'where', loc(upd.whereClause), byteFrom);
    pushIf(starts, 'returning', loc(upd.returningList), byteFrom);
  }
  if ('DeleteStmt' in ast) {
    const del = (ast.DeleteStmt ?? {}) as Record<string, unknown>;
    pushIf(starts, 'with', loc(del.withClause), byteFrom);
    pushIf(starts, 'from', loc(del.relation), byteFrom);
    pushIf(starts, 'using', loc(del.usingClause), byteFrom);
    pushIf(starts, 'where', loc(del.whereClause), byteFrom);
    pushIf(starts, 'returning', loc(del.returningList), byteFrom);
  }

  const sorted = [...new Map(starts.map((s) => [s.clause, s.byte])).entries()].sort((a, b) => a[1] - b[1]);
  return sorted.map(([clause, byte], i) => {
    const from = stmt.from + byteToChar(stmt.text, byte);
    const nextByte = i + 1 < sorted.length ? sorted[i + 1][1] : stmtBytes;
    const to = stmt.from + byteToChar(stmt.text, nextByte);
    return { clause, from, to: Math.max(from, to) };
  });
}

// Клауз под курсором
export function clauseAt(stmt: ParsedStatement, cursor: number): ClauseName | null {
  for (const r of clauseRanges(stmt)) {
    if (cursor >= r.from && cursor < r.to) return r.clause;
  }
  return null;
}

// Позиция начала узла: сам узел, первый элемент списка, обёртка SortBy.node или valuesLists
function loc(node: unknown): number | null {
  if (node == null) return null;
  if (Array.isArray(node)) {
    for (const item of node) {
      const found = loc(item);
      if (found != null) return found;
    }
    return null;
  }
  if (typeof node !== 'object') return null;
  const rec = node as Record<string, unknown>;
  if (typeof rec.location === 'number') return rec.location;
  const inner = loc(rec.node); // SortBy и подобные обёртки
  if (inner != null) return inner;
  return loc(rec.valuesLists); // valuesLists - список списков
}

// loc() отдаёт абсолютные байты полного текста; внутри оператора работаем в относительных
function pushIf(starts: Array<{ clause: ClauseName; byte: number }>, clause: ClauseName, byte: number | null, byteFrom = 0): void {
  if (byte != null) starts.push({ clause, byte: byte - byteFrom });
}
```

```tsx
import { PostgreSQL, sql } from '@codemirror/lang-sql';
import { keymap } from '@codemirror/commands';
import { linter } from '@codemirror/lint';
import type { ViewUpdate } from '@codemirror/view';
import CodeMirror from '@uiw/react-codemirror';
import { useMemo, useRef } from 'react';
import { useResolvedTheme } from '@/app/ThemeProvider';
import { useEditorStore } from '@/stores/editor';
import { editorTheme } from './theme';

// linter(() => []) обязателен: расширение lint регистрирует StateField,
// в который эффектами кладутся программные диагностики (setDiagnostics, задачи 8)
export function SqlEditor({ onApply }: { onApply?: () => void }) {
  const text = useEditorStore((s) => s.text);
  const setText = useEditorStore((s) => s.setText);
  const setCursor = useEditorStore((s) => s.setCursor);
  const resolved = useResolvedTheme();

  // onApply меняется каждый рендер панели: замыкаем через ref, чтобы extensions не пересоздавались
  const applyRef = useRef(onApply);
  applyRef.current = onApply;

  const extensions = useMemo(
    () => [
      sql({ dialect: PostgreSQL, upperCaseKeywords: false }),
      linter(() => []),
      keymap.of([
        {
          key: 'Mod-Enter',
          run: () => {
            applyRef.current?.();
            return true;
          },
        },
      ]),
      editorTheme(),
    ],
    [],
  );

  return (
    <CodeMirror
      value={text}
      theme={resolved}
      height="100%"
      extensions={extensions}
      onChange={setText}
      onUpdate={(vu: ViewUpdate) => {
        if (vu.selectionSet || vu.docChanged) setCursor(vu.state.selection.main.head);
      }}
    />
  );
}
```

```ts
import type { SchemaSnapshot } from '@/features/db/introspect';

// Спецификация для встроенного автодополнения @codemirror/lang-sql:
// { 'public.book': ['book_id', ...], book: ['book_id', ...] }.
// Короткое имя не добавляем, если таблица с таким именем есть в нескольких схемах.
export function buildSchemaSpec(schema: SchemaSnapshot): Record<string, readonly string[]> {
  const spec: Record<string, readonly string[]> = {};
  const byName = new Map<string, number>();
  for (const t of schema.tables) byName.set(t.name, (byName.get(t.name) ?? 0) + 1);
  for (const t of schema.tables) {
    spec[t.id] = t.columns.map((c) => c.name);
    if ((byName.get(t.name) ?? 0) === 1) spec[t.name] = t.columns.map((c) => c.name);
  }
  return spec;
}
```

```ts
import type { SchemaSnapshot, TableInfo } from '@/features/db/introspect';
import { relationsOf } from '@/features/sql/relations';
import type { ColumnRef, ParsedStatement, RangeRef } from '@/features/sql/types';

// Какие таблицы и колонки оператора существуют в текущей схеме (для фокуса доски).
// Неизвестные таблицы (CTE, TEMP до Ф10, функции) пропускаем молча.
export function touchedOf(stmt: ParsedStatement, schema: SchemaSnapshot | null): { tableIds: string[]; columns: string[] } {
  if (!schema) return { tableIds: [], columns: [] };
  const rel = relationsOf(stmt);
  const tableIds: string[] = [];
  const tables: RangeRef[] = [];
  for (const t of rel.tables) {
    const info = resolveTable(t, schema);
    if (!info) continue;
    if (!tableIds.includes(info.id)) tableIds.push(info.id);
    tables.push(t);
  }
  const columns: string[] = [];
  for (const c of rel.columns) {
    const resolved = resolveColumn(c, tables, schema);
    if (resolved && !columns.includes(resolved.id)) columns.push(resolved.id);
  }
  return { tableIds, columns };
}

export function resolveColumn(
  column: ColumnRef,
  tables: RangeRef[],
  schema: SchemaSnapshot | null,
): { id: string; type: string } | null {
  if (!schema) return null;
  let target: TableInfo | null = null;
  if (column.qualifier) {
    for (const t of tables) {
      if (t.alias === column.qualifier || t.name === column.qualifier) {
        target = resolveTable(t, schema);
        break;
      }
    }
  } else {
    // без квалификатора: колонка должна быть ровно в одной таблице запроса
    const found: TableInfo[] = [];
    for (const t of tables) {
      const info = resolveTable(t, schema);
      if (info?.columns.some((c) => c.name === column.name)) found.push(info);
    }
    target = found.length === 1 ? found[0] : null;
  }
  const col = target?.columns.find((c) => c.name === column.name);
  return target && col ? { id: `${target.id}.${col.name}`, type: col.type } : null;
}

// Резолв ссылки таблицы: схема-имя, иначе имя без схемы (public имеет приоритет, иначе единственная)
function resolveTable(ref: RangeRef, schema: SchemaSnapshot): TableInfo | null {
  const candidates = schema.tables.filter((t) => t.name === ref.name && (ref.schema == null || t.schema === ref.schema));
  if (ref.schema != null) return candidates[0] ?? null;
  return candidates.find((t) => t.schema === 'public') ?? (candidates.length === 1 ? candidates[0] : null);
}
```

```ts
import type { DbError } from '@/features/db/types';

export interface EditorDiagnostic {
  from: number;
  to: number;
  message: string;
}

// Слово под позицией: диагностика подчёркивает лексему, а не один символ
function wordAt(text: string, at: number): { from: number; to: number } {
  const from = Math.max(0, Math.min(at, Math.max(0, text.length - 1)));
  const m = /[\w$]+/.exec(text.slice(from));
  return m ? { from: from + m.index, to: from + m.index + m[0].length } : { from, to: from + 1 };
}

// Ошибка парсинга: position - символьная, 0-based, уже в координатах редактора
export function parseDiagnostic(text: string, err: { message: string; position: number }): EditorDiagnostic {
  return { ...wordAt(text, err.position), message: err.message };
}

// Ошибка Postgres: position 1-based от начала оператора, переводим в абсолютную позицию редактора.
// ponytail: оператор ищется первым вхождением текста; дубликат оператора в редакторе
// подчеркнёт первый. Обновление - хранить from в трейсе, когда Ф5 строит трейс из ParsedStatement.
export function pgDiagnostic(text: string, stmtSql: string, err: DbError): EditorDiagnostic | null {
  if (err.position == null) return null;
  const stmtFrom = text.indexOf(stmtSql);
  if (stmtFrom < 0) return null;
  return { ...wordAt(text, stmtFrom + err.position - 1), message: err.message };
}
```

```ts
import { useEffect, useMemo, useState } from 'react';
import type { Sandbox } from '@/features/db/sandbox';
import type { DbError } from '@/features/db/types';
import { DbException } from '@/features/db/types';
import { initParser, parseSql } from '@/features/sql/parser';
import { statementAt } from '@/features/sql/statements';
import type { Trace } from '@/features/tracer/types';
import { useBoardStore } from '@/stores/board';
import { useEditorStore } from '@/stores/editor';
import { useSceneStore } from '@/stores/scene';
import { touchedOf } from './touched';

const DEBOUNCE_MS = 250;

// Живое превью (спека 5.3, без трассировщика до Ф5): парсим текст, берём оператор под
// курсором, выполняем его в транзакции песочницы и кладём Trace «только итог».
// Поколения защищают от гонки: setTrace отбрасывает ответ устаревшего запроса.
export function useLiveTrace(sandbox: Sandbox | null): void {
  const text = useEditorStore((s) => s.text);
  const cursor = useEditorStore((s) => s.cursor);
  const schema = useBoardStore((s) => s.schema);
  const [parserReady, setParserReady] = useState(false);
  const [dataVersion, setDataVersion] = useState(0);

  useEffect(() => {
    void initParser().then(() => setParserReady(true));
  }, []);

  // После apply/undo/reset/loadLesson песочница шлёт changed: данные изменились, превью перевыполняем
  useEffect(() => {
    if (!sandbox) return;
    return sandbox.subscribe((e) => {
      if (e.type === 'changed') setDataVersion((v) => v + 1);
    });
  }, [sandbox]);

  const stmtIndex = useMemo(() => {
    if (!parserReady || text.trim() === '') return -1;
    const parsed = parseSql(text);
    return parsed.ok ? (statementAt(parsed.statements, cursor)?.index ?? -1) : -1;
  }, [parserReady, text, cursor]);

  // Курсор читаем внутри таймера, а не замыкаем: иначе эффект пришлось бы перезапускать
  // на каждое движение курсора. dataVersion обновляет превью при изменении данных,
  // stmtIndex - при переводе курсора в другой оператор.
  useEffect(() => {
    if (!sandbox || !parserReady) return;
    const generation = useSceneStore.getState().nextGeneration();
    const timer = setTimeout(() => {
      const cursor = useEditorStore.getState().cursor;
      void runPreview(text, cursor, generation, sandbox, schema);
    }, DEBOUNCE_MS);
    return () => clearTimeout(timer);
  }, [sandbox, parserReady, text, stmtIndex, dataVersion, schema]);
}

async function runPreview(
  text: string,
  cursor: number,
  generation: number,
  sandbox: Sandbox,
  schema: ReturnType<typeof useBoardStore.getState>['schema'],
): Promise<void> {
  const editor = useEditorStore.getState();
  const scene = useSceneStore.getState();
  const parsed = parseSql(text);
  if (!parsed.ok) {
    // недописанный запрос: подчёркиваем, последняя валидная сцена остаётся и гаснет, без мигания
    editor.setParseError(parsed.error);
    scene.setStale(true);
    return;
  }
  editor.setParseError(null);
  const stmt = statementAt(parsed.statements, cursor);
  if (!stmt) {
    scene.close();
    return;
  }
  const started = performance.now();
  const base = {
    sql: stmt.text,
    statementType: stmt.kind,
    mode: 'final-only' as const,
    fallbackReason: 'Пошаговый разбор запроса появится позже', // Ф5 подменит на traceStatement
    touched: touchedOf(stmt, schema),
    stages: [],
    notices: [],
  };
  try {
    const result = await sandbox.preview((db) => db.query(stmt.text));
    useSceneStore.getState().setTrace({ ...base, result, error: null, timingMs: Math.round(performance.now() - started) }, generation);
  } catch (e) {
    const error: DbError = e instanceof DbException ? e.db : { code: 'VS000', message: String(e) };
    useSceneStore
      .getState()
      .setTrace({ ...base, result: null, error, timingMs: Math.round(performance.now() - started) }, generation);
  }
}
```

```tsx
import { useVirtualizer } from '@tanstack/react-virtual';
import { useRef } from 'react';
import { formatCell } from '@/features/board/format';
import type { QueryResult } from '@/features/db/types';

// Виртуализированная таблица результата: моно-шрифт, NULL-плашки как на доске
export function ResultGrid({ result, emptyHint }: { result: QueryResult; emptyHint?: string }) {
  const scrollRef = useRef<HTMLDivElement>(null);
  const rows = result.rows;
  // initialRect: jsdom без layout, тесты иначе не увидят ни одной строки
  const virtualizer = useVirtualizer({
    count: rows.length,
    getScrollElement: () => scrollRef.current,
    estimateSize: () => 28,
    overscan: 12,
    initialRect: { width: 800, height: 400 },
  });

  if (rows.length === 0) {
    return (
      <div data-testid="result-grid" className="grid h-full place-items-center">
        <p data-testid="result-empty" className="text-sm text-muted-foreground">
          {emptyHint ?? '0 строк'}
        </p>
      </div>
    );
  }

  return (
    <div data-testid="result-grid" className="flex h-full min-h-0 flex-col">
      <div className="flex shrink-0 border-b bg-muted/40 font-mono text-xs">
        {result.fields.map((f) => (
          <div key={f.name} data-testid={`field-${f.name}`} className="min-w-24 flex-1 truncate px-2 py-1 font-semibold" title={f.name}>
            {f.name}
          </div>
        ))}
      </div>
      <div ref={scrollRef} className="min-h-0 flex-1 overflow-auto">
        <div style={{ height: virtualizer.getTotalSize(), position: 'relative' }}>
          {virtualizer.getVirtualItems().map((item) => {
            const row = rows[item.index];
            return (
              <div
                key={item.key}
                data-testid={`row-${item.index}`}
                className="absolute left-0 flex w-full font-mono text-xs hover:bg-muted/50"
                style={{ top: item.start, height: item.size }}
              >
                {row.map((cell, i) => (
                  <Cell key={i} row={item.index} col={i} value={cell} />
                ))}
              </div>
            );
          })}
        </div>
      </div>
    </div>
  );
}

function Cell({ row, col, value }: { row: number; col: number; value: unknown }) {
  const cell = formatCell(value);
  return (

      {cell.kind === 'null' ? <span className="italic text-muted-foreground">NULL</span> : cell.text}
    </div>
  );
}
```

```tsx
import { LoaderCircle } from 'lucide-react';
import { useEffect, useMemo, useState } from 'react';
import { toast } from 'sonner';
import type { Sandbox } from '@/features/db/sandbox';
import { DbException } from '@/features/db/types';
import { parseSql } from '@/features/sql/parser';
import { useEditorStore } from '@/stores/editor';
import { useSceneStore } from '@/stores/scene';

const STATUS_LABEL: Record<'idle' | 'tracing' | 'ready' | 'error', string> = {
  idle: 'Превью',
  tracing: 'Считаем',
  ready: 'Превью',
  error: 'Ошибка',
};

// Строка управления под редактором. Применение текущего оператора идёт через
// onApplyCurrent: один путь для кнопки, ⌘⏎ из keymap CodeMirror и ⌘⏎ вне редактора.
export function EditorToolbar({ sandbox, onApplyCurrent }: { sandbox: Sandbox | null; onApplyCurrent: () => void }) {
  const status = useSceneStore((s) => s.status);
  const stale = useSceneStore((s) => s.stale);
  const text = useEditorStore((s) => s.text);
  const [busy, setBusy] = useState(false);
  const [journalLength, setJournalLength] = useState(0);

  // длина журнала: для блокировки «Отменить»
  useEffect(() => {
    if (!sandbox) return;
    const sync = () => setJournalLength(sandbox.journal().length);
    sync();
    return sandbox.subscribe((e) => {
      if (e.type === 'changed') sync();
    });
  }, [sandbox]);

  const statementCount = useMemo(() => {
    if (text.trim() === '') return 0;
    const parsed = parseSql(text);
    return parsed.ok ? parsed.statements.length : 0;
  }, [text]);

  const statements = useMemo(() => {
    const parsed = parseSql(text);
    return parsed.ok ? parsed.statements : [];
  }, [text]);

  const run = async (fn: () => Promise<unknown>) => {
    setBusy(true);
    try {
      await fn();
    } catch (e) {
      // ошибки применения показываем тостом; превью оператора продублирует её в «Сообщениях»
      const message = e instanceof DbException ? e.db.message : String(e);
      toast.error('Не получилось', { description: message });
    } finally {
      setBusy(false);
    }
  };

  const applyAll = () =>
    void run(async () => {
      for (const s of statements) await sandbox?.apply(s.text);
    });

  return (
    <div className="flex shrink-0 items-center gap-2 border-t px-2 py-1">
      <Badge variant="outline" data-testid="preview-status" className="gap-1.5 text-xs">
        {status === 'tracing' ? <LoaderCircle className="size-3 animate-spin" aria-hidden /> : <span aria-hidden>●</span>}
        {stale ? 'Недописан' : STATUS_LABEL[status]}
      </Badge>
      <div className="ml-auto flex items-center gap-1.5">
        {statementCount > 1 && (
          <Button variant="outline" size="sm" data-testid="apply-all-button" disabled={busy || !sandbox} onClick={applyAll}>
            Применить всё
          </Button>
        )}
        <Button variant="outline" size="sm" data-testid="undo-button" disabled={busy || !sandbox || journalLength === 0} onClick={() => void run(() => sandbox?.undo())}>
          Отменить
        </Button>
        <Button variant="outline" size="sm" data-testid="reset-button" disabled={busy || !sandbox} onClick={() => void run(() => sandbox?.reset())}>
          Сброс
        </Button>
        <Button size="sm" data-testid="apply-button" disabled={busy || !sandbox || statementCount === 0} onClick={onApplyCurrent}>
          Применить <Kbd>⌘⏎</Kbd>
        </Button>
      </div>
    </div>
  );
}
```

```ts
import { parseSql } from '@/features/sql/parser';
import { relationsOf } from '@/features/sql/relations';
import { statementAt } from '@/features/sql/statements';
import type { ColumnRef, RangeRef } from '@/features/sql/types';

// Колонка под позицией курсора и таблицы её оператора (для hover-тултипа и подсветки на доске)
export function columnContextAt(text: string, pos: number): { column: ColumnRef; tables: RangeRef[] } | null {
  const parsed = parseSql(text);
  if (!parsed.ok) return null;
  const stmt = statementAt(parsed.statements, pos);
  if (!stmt) return null;
  const rel = relationsOf(stmt);
  const column = rel.columns.find((c) => pos >= c.from && pos <= c.to);
  return column ? { column, tables: rel.tables } : null;
}
```

```ts
import { StateEffect, StateField, type Extension } from '@codemirror/state';
import { Decoration, EditorView, type DecorationSet } from '@codemirror/view';

// Диапазон активного клауза из React-мира (эффект EditorPane) в декорацию CodeMirror
export const setActiveClauseRange = StateEffect.define<{ from: number; to: number } | null>();

const mark = Decoration.mark({ class: 'cm-clauseActive' });

const clauseField = StateField.define<DecorationSet>({
  create: () => Decoration.none,
  update(value, tr) {
    let next = value.map(tr.changes, tr.doc);
    for (const e of tr.effects) {
      if (e.is(setActiveClauseRange)) {
        next = e.value ? Decoration.set([mark.range(e.value.from, e.value.to)]) : Decoration.none;
      }
    }
    return next;
  },
  provide: (field) => EditorView.decorations.from(field),
});

export function clauseHighlight(): Extension {
  return [clauseField];
}
```
