# Ф3 «Базовая доска»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Правая колонка показывает настоящую схему песочницы как miro-подобную доску: таблицы с колонками, иконками ограничений и первыми 15 строками, FK-рёбра с «вороньей лапкой», рамки схем, раскладка dagre с переопределением из урока, pan/zoom, миникарта, `⌘0`, камера по уроку, скелетон загрузки, пустое состояние и версия Postgres. Остальные модули управляют доской только через `useBoardStore` (`focus`, `highlightColumns`, `setDimmed`, `requestFit`), и это не пересобирает ноды.

**Architecture:** Чистые функции `layout.ts` (размеры таблиц, dagre по каждой схеме, схемы стоят рядом слева направо) и `model.ts` (React Flow ноды и рёбра из `SchemaSnapshot`) тестируются в Node. `BoardCanvas` строит ноды в `useMemo` только от `schema`, `visibleTables` и урока. Фокус и подсветку `TableNode` читает из стора селекторами, поэтому при `focus()` перерисовывается только затронутая таблица, а камера двигается через `fitView`. Схему в стор кладёт хук `useSchemaSync` из `features/shell`: он слушает событие песочницы `changed` и вызывает `introspect`. Доска про БД и запросы не знает.

**Tech Stack:** React 19.3, TypeScript strict, `@xyflow/react@12.12.0`, `@dagrejs/dagre@3.1.1`, zustand 5, Tailwind v4 + shadcn (`badge`, `skeleton` уже есть с Ф1), lucide-react, Vitest 5 (проекты node и dom), Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-08-visual-sql-design.md`, разделы 3.4, 5.8, 5.12, 5.13, 9. Контракты: `docs/superpowers/plans/2026-10-08-00-contracts.md`, разделы 3, 4 (`introspect.ts`, `SandboxProvider.tsx`), 7 (`board.ts`, `lesson.ts`), 8 (`LessonMeta.board`), 9.

## Review Focus

1. **Фокус не пересобирает ноды.** `focus(['public.author'])` перерисовывает только `TableNode` автора, нода `book` не рендерится. Тест «фокус перерисовывает только свою таблицу» с `React.Profiler` (задача 4).
2. **NULL и пустая строка различимы.** NULL рисуется плашкой `NULL` (курсив, пунктир), `''` рисуется как `''` приглушённо. Тесты `formatCell` (задача 1) и «NULL и пустая строка выглядят по-разному» (задача 4).
3. **Раскладка читаемая.** Таблицы не перекрываются, таблица, на которую ссылаются, стоит левее ссылающейся, вторая схема правее первой. Тест `autoLayout` (задача 1) и e2e «bookstore разложен без наложений» (задача 6).
4. **Повторный `focus` того же набора не дёргает камеру.** `focusRequest` растёт только при смене набора таблиц, `highlightColumns` с тем же списком не меняет состояние. Тест стора (задача 3).
5. **Камера урока сохраняет только движения пользователя.** Программные `fitView` (фокус, `⌘0`) не пишут viewport, колесо мыши пишет, после перезагрузки камера на месте. E2e «камера урока переживает перезагрузку» (задача 6).

```ts
export interface FormattedCell {
  text: string;
  kind: 'null' | 'empty' | 'value';
}

const MAX_LEN = 60;

// Текст ячейки для доски и панели результата. NULL и '' разные вещи, поэтому у них свой kind
export function formatCell(value: unknown, type?: string): FormattedCell {
  if (value === null || value === undefined) return { text: 'NULL', kind: 'null' };
  if (value === '') return { text: "''", kind: 'empty' };
  const text = toText(value, type);
  return { text: text.length > MAX_LEN ? `${text.slice(0, MAX_LEN - 1)}…` : text, kind: 'value' };
}

function toText(value: unknown, type?: string): string {
  // PGlite отдаёт date как полночь UTC, timestamp/timestamptz как Date
  if (value instanceof Date) {
    return type === 'date' ? value.toISOString().slice(0, 10) : value.toISOString().replace('T', ' ').replace(/\.\d{3}Z$/, 'Z');
  }
  if (Array.isArray(value)) return `{${value.map((v) => (v === null ? 'NULL' : String(v))).join(',')}}`;
  if (typeof value === 'object') return JSON.stringify(value);
  return String(value);
}
```

```ts
import dagre from '@dagrejs/dagre';
import type { SchemaSnapshot, TableInfo } from '@/features/db/introspect';

export const TABLE_WIDTH = 260;
export const ROW_HEIGHT = 24;
export const HEADER_HEIGHT = 36;
export const MAX_VISIBLE_ROWS = 15;
export const COLUMN_WIDTH = 132;
export const COLUMN_HEADER_HEIGHT = 40;
export const SCHEMA_GAP = 120;

export type Positions = Record<string, { x: number; y: number }>;

export function tableWidth(t: TableInfo): number {
  return Math.max(TABLE_WIDTH, t.columns.length * COLUMN_WIDTH);
}

// Шапка + заголовки колонок + видимые строки + строка «+ ещё N» или «пусто»
export function tableHeight(t: TableInfo): number {
  const visible = Math.min(t.sampleRows.length, MAX_VISIBLE_ROWS);
  const footer = t.rowCount > visible || t.rowCount === 0 ? ROW_HEIGHT : 0;
  return HEADER_HEIGHT + COLUMN_HEADER_HEIGHT + visible * ROW_HEIGHT + footer;
}

export function isTableVisible(visible: string[] | null, id: string): boolean {
  return visible === null || visible.includes(id);
}

// Порядок схем: как в снимке, плюс схемы таблиц, которых там нет
export function schemaNames(schema: SchemaSnapshot): string[] {
  return [...new Set([...schema.schemas, ...schema.tables.map((t) => t.schema)])];
}

// dagre слева направо отдельно по каждой схеме; схемы стоят рядом с зазором SCHEMA_GAP.
// Межсхемные FK в раскладке не участвуют, чтобы рамки схем не пересекались.
export function autoLayout(schema: SchemaSnapshot, visible: string[] | null): Positions {
  const result: Positions = {};
  let offsetX = 0;
  for (const name of schemaNames(schema)) {
    const tables = schema.tables.filter((t) => t.schema === name && isTableVisible(visible, t.id));
    if (tables.length === 0) continue;

    const g = new dagre.graphlib.Graph();
    g.setGraph({ rankdir: 'LR', nodesep: 60, ranksep: 120 });
    g.setDefaultEdgeLabel(() => ({}));
    for (const t of tables) g.setNode(t.id, { width: tableWidth(t), height: tableHeight(t) });
    for (const fk of schema.fks) {
      const { tableId: from } = fk.from;
      const { tableId: to } = fk.to;
      // ребро от таблицы, на которую ссылаются, поэтому она оказывается левее
      if (from !== to && g.hasNode(from) && g.hasNode(to)) g.setEdge(to, from);
    }
    dagre.layout(g);

    const local = tables.map((t) => {
      const n = g.node(t.id);
      return { id: t.id, x: n.x - n.width / 2, y: n.y - n.height / 2, right: n.x + n.width / 2 };
    });
    const minX = Math.min(...local.map((p) => p.x));
    const minY = Math.min(...local.map((p) => p.y));
    const maxX = Math.max(...local.map((p) => p.right));
    for (const p of local) result[p.id] = { x: offsetX + p.x - minX, y: p.y - minY };
    offsetX += maxX - minX + SCHEMA_GAP;
  }
  return result;
}
```

```ts
import type { Edge, Node } from '@xyflow/react';
import type { FkInfo, SchemaSnapshot, TableInfo } from '@/features/db/introspect';
import { autoLayout, isTableVisible, type Positions, schemaNames, tableHeight, tableWidth } from './layout';

// Фокус и подсветку нода читает из useBoardStore, поэтому в data только таблица
export interface TableNodeData extends Record<string, unknown> {
  table: TableInfo;
}
export interface SchemaGroupData extends Record<string, unknown> {
  schema: string;
}
export interface FkEdgeData extends Record<string, unknown> {
  fk: FkInfo;
}
export type TableFlowNode = Node<TableNodeData, 'table'>;
export type SchemaFlowNode = Node<SchemaGroupData, 'schemaGroup'>;
export type BoardNode = TableFlowNode | SchemaFlowNode;
export type FkFlowEdge = Edge<FkEdgeData, 'fk'>;

export const GROUP_PADDING = 24;
export const GROUP_LABEL = 28;

export function normalizeTableId(name: string): string {
  return name.includes('.') ? name : `public.${name}`;
}

// Автораскладка, поверх неё координаты из frontmatter урока (имена без схемы считаются public)
export function resolvePositions(
  schema: SchemaSnapshot,
  visible: string[] | null,
  layout?: 'auto' | Record<string, { x: number; y: number }>,
): Positions {
  const auto = autoLayout(schema, visible);
  if (!layout || layout === 'auto') return auto;
  const manual = Object.fromEntries(Object.entries(layout).map(([name, p]) => [normalizeTableId(name), p]));
  return { ...auto, ...manual };
}

export function buildNodes(schema: SchemaSnapshot, visible: string[] | null, positions: Positions): BoardNode[] {
  const groups: SchemaFlowNode[] = [];
  const tables: TableFlowNode[] = [];
  for (const name of schemaNames(schema)) {
    const members = schema.tables.filter((t) => t.schema === name && isTableVisible(visible, t.id) && positions[t.id]);
    if (members.length === 0) continue;

    const boxes = members.map((t) => {
      const p = positions[t.id] ?? { x: 0, y: 0 };
      return { t, x: p.x, y: p.y, w: tableWidth(t), h: tableHeight(t) };
    });
    const minX = Math.min(...boxes.map((b) => b.x));
    const minY = Math.min(...boxes.map((b) => b.y));
    const maxX = Math.max(...boxes.map((b) => b.x + b.w));
    const maxY = Math.max(...boxes.map((b) => b.y + b.h));
    const gx = minX - GROUP_PADDING;
    const gy = minY - GROUP_PADDING - GROUP_LABEL;
    const groupId = `schema:${name}`;

    groups.push({
      id: groupId,
      type: 'schemaGroup',
      position: { x: gx, y: gy },
      data: { schema: name },
      width: maxX - minX + 2 * GROUP_PADDING,
      height: maxY - minY + 2 * GROUP_PADDING + GROUP_LABEL,
      selectable: false,
      focusable: false,
    });
    for (const b of boxes) {
      tables.push({
        id: b.t.id,
        type: 'table',
        parentId: groupId,
        position: { x: b.x - gx, y: b.y - gy },
        data: { table: b.t },
        width: b.w,
        height: b.h,
      });
    }
  }
  // React Flow требует, чтобы родитель шёл раньше детей
  return [...groups, ...tables];
}

export function buildEdges(schema: SchemaSnapshot, visible: string[] | null): FkFlowEdge[] {
  const known = new Set(schema.tables.map((t) => t.id));
  return schema.fks
    .filter((fk) => known.has(fk.from.tableId) && known.has(fk.to.tableId))
    .filter((fk) => isTableVisible(visible, fk.from.tableId) && isTableVisible(visible, fk.to.tableId))
    .map((fk) => ({
      id: `${fk.name}:${fk.from.tableId}`,
      type: 'fk',
      source: fk.to.tableId,
      target: fk.from.tableId,
      data: { fk },
      selectable: false,
      focusable: false,
    }));
}
```

```ts
import { create } from 'zustand';
import type { SchemaSnapshot } from '@/features/db/introspect';

export interface BoardStore {
  schema: SchemaSnapshot | null;
  visibleTables: string[] | null;
  focused: string[];
  highlightedColumns: string[];
  dimmed: boolean;
  fitRequest: number;
  focusRequest: number;
  setSchema(s: SchemaSnapshot): void;
  setVisibleTables(t: string[] | null): void;
  focus(tableIds: string[]): void;
  highlightColumns(cols: string[]): void;
  setDimmed(v: boolean): void;
  requestFit(): void;
}

const sameSet = (a: string[], b: string[]) => a.length === b.length && a.every((x) => b.includes(x));
const sameList = (a: string[], b: string[]) => a.length === b.length && a.every((x, i) => x === b[i]);

export const useBoardStore = create<BoardStore>()((set) => ({
  schema: null,
  visibleTables: null,
  focused: [],
  highlightedColumns: [],
  dimmed: false,
  fitRequest: 0,
  focusRequest: 0,
  setSchema: (schema) => set({ schema }),
  setVisibleTables: (visibleTables) => set({ visibleTables }),
  // Камера летит только при смене набора: ввод в редакторе вызывает focus на каждый символ
  focus: (tableIds) =>
    set((s) => (sameSet(s.focused, tableIds) ? s : { focused: tableIds, focusRequest: s.focusRequest + 1 })),
  highlightColumns: (cols) => set((s) => (sameList(s.highlightedColumns, cols) ? s : { highlightedColumns: cols })),
  setDimmed: (dimmed) => set({ dimmed }),
  requestFit: () => set((s) => ({ fitRequest: s.fitRequest + 1 })),
}));
```

```tsx
export const CellValue = memo(function CellValue({ value, type }: { value: unknown; type?: string }) {
  const cell = formatCell(value, type);
  if (cell.kind === 'null') {

        {cell.text}
      </span>
    );
  }
  return (
    <span data-kind="value" className="truncate" title={cell.text}>
      {cell.text}
    </span>
  );
});
```

```tsx
import type { TableFlowNode } from './model';

export function columnTitle(c: ColumnInfo): string {
  return [
    `${c.name}: ${c.type}`,
    c.isPk && 'PRIMARY KEY',
    c.fk && `REFERENCES ${c.fk.schema}.${c.fk.table} (${c.fk.column})`,
    !c.nullable && 'NOT NULL',
    c.isUnique && 'UNIQUE',

    c.default !== null && `DEFAULT ${c.default}`,
    ...c.checks,
  ]
```

```tsx
export function selfLoopPath(sx: number, sy: number, tx: number, ty: number): string {
```

```ts
import { useEffect } from 'react';
import { MAX_VISIBLE_ROWS } from '@/features/board/layout';
import { introspect } from '@/features/db/introspect';
import { useSandbox } from '@/features/db/SandboxProvider';
import { useBoardStore } from '@/stores/board';

// Доска перерисовывается только здесь: после загрузки урока и после «Применить» (событие changed)
export function useSchemaSync(): void {
  const { sandbox } = useSandbox();

  useEffect(() => {
    if (!sandbox) return;
    let alive = true;
    let generation = 0;

    const sync = async () => {
      const mine = ++generation;
      try {
        const schema = await introspect(sandbox.client(), { sampleRows: MAX_VISIBLE_ROWS });
        if (alive && mine === generation) useBoardStore.getState().setSchema(schema);
      } catch (e) {
        // песочница перезапускается и пришлёт changed ещё раз; старая схема остаётся на доске
        console.error('introspect', e);
      }
    };

    if (sandbox.status === 'ready') void sync();
    const off = sandbox.subscribe((e) => {
      if (e.type === 'changed') void sync();
    });
    return () => {
      alive = false;
      off();
    };
  }, [sandbox]);
}
```

```tsx
  const flow = useReactFlow();
  const initialized = useNodesInitialized();
  const restoredFor = useRef<string | null>(null);
  const fitRequest = useBoardStore((s) => s.fitRequest);
  const focusRequest = useBoardStore((s) => s.focusRequest);
  const nodeKey = useMemo(() => nodes.map((n) => n.id).join('|'), [nodes]);

  // Сохранённая камера урока ставится один раз; без неё вписываем доску при каждой смене набора нод
  useEffect(() => {
    if (!initialized || nodeKey === '') return;
    const saved = lessonId ? useLessonStore.getState().byId[lessonId]?.viewport : undefined;
    if (!saved) {
      void flow.fitView({ padding: 0.15 });
    } else if (restoredFor.current !== lessonId) {
      restoredFor.current = lessonId;
      void flow.setViewport(saved);
    }
  }, [initialized, nodeKey, lessonId, flow]);

  useEffect(() => {
    if (fitRequest > 0) void flow.fitView({ padding: 0.15, duration: 300 });
  }, [fitRequest, flow]);

  useEffect(() => {
    const ids = useBoardStore.getState().focused;
    if (focusRequest > 0 && ids.length > 0) {
      void flow.fitView({ nodes: ids.map((id) => ({ id })), padding: 0.3, duration: 400, maxZoom: 1 });
    }
  }, [focusRequest, flow]);

  // ⌘0 / Ctrl+0: по event.code, на русской раскладке key другой; preventDefault гасит сброс зума браузера
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if ((e.metaKey || e.ctrlKey) && !e.altKey && e.code === 'Digit0') {
        e.preventDefault();
        useBoardStore.getState().requestFit();
      }
    };
    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, []);
}
```

```tsx
import { Badge } from '@/components/ui/badge';
import { Skeleton } from '@/components/ui/skeleton';
import type { Sandbox } from '@/features/db/sandbox';
import { useBoardStore } from '@/stores/board';
import { isTableVisible } from './layout';

export function pgVersionLabel(version: string | null): string | null {
  const m = version?.match(/PostgreSQL (\d+(?:\.\d+)?)/);
  return m ? `PostgreSQL ${m[1]} в браузере` : null;
}

// Слои поверх доски: загрузка, пустая схема, сбой, версия Postgres
export function BoardStatus({ status, version }: { status: Sandbox['status']; version: string | null }) {
  const schema = useBoardStore((s) => s.schema);
  const visible = useBoardStore((s) => s.visibleTables);
  const loading = status === 'booting' || status === 'restarting' || (status === 'ready' && schema === null);
  const empty = schema !== null && !schema.tables.some((t) => isTableVisible(visible, t.id));
  const label = pgVersionLabel(version);

  return (
    <>
      {loading && (
        <div role="status" data-testid="board-skeleton" className="absolute inset-0 z-10 grid place-items-center bg-background/80">
          <div className="flex flex-col items-center gap-4">
            <div className="flex items-start gap-4">
              <Skeleton className="h-28 w-40" />
              <Skeleton className="h-40 w-52" />
              <Skeleton className="h-24 w-36" />
            </div>
            <p className="text-sm text-muted-foreground">Поднимаем Postgres...</p>
          </div>
        </div>
      )}
      {status === 'failed' && (
        <div role="alert" className="absolute inset-0 z-10 grid place-items-center bg-background/80 text-sm text-destructive">
          Postgres не запустился. Обнови страницу.
        </div>
      )}
      {!loading && status !== 'failed' && empty && (
        <div data-testid="board-empty" className="pointer-events-none absolute inset-0 grid place-items-center">
          <p className="text-sm text-muted-foreground">
            Создай первую таблицу: <code className="font-mono">create table ...</code>
          </p>
        </div>
      )}
      {label && (
        <Badge variant="outline" data-testid="pg-version" className="absolute right-2 bottom-2 z-10 bg-background">
          {label}
        </Badge>
      )}
    </>
  );
}
```
