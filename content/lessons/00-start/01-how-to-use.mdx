<TlDr>Запрос выполняется сам, пока ты печатаешь, но данные меняет только «Применить».</TlDr>

## Что есть в данных

В датасете `bookstore` 8 таблиц книжного магазина: книги, авторы, покупатели, заказы и другие. На доске этого урока только две: <T id="public.book">book</T> на 11 книг и <T id="public.author">author</T> на 6 авторов. Остальные таблицы тоже в базе, запросы к ним работают.

У одной книги, «Острова погибших кораблей», не указана цена. Запомни её: в сцене ниже она пропадёт из выдачи.

## Экран

Слева темы, в центре этот текст, справа рабочая колонка. Сверху вниз в ней идут доска с таблицами, полоса плеера, редактор и панель результата.

У каждой таблицы на доске есть шапка с именем и числом строк, под ней колонки с типами и сами данные.

Доску можно двигать:

- тянешь мышью: камера едет;
- крутишь колесо: зум;
- `⌘0` (`Ctrl+0` на Windows), когда курсор над доской: вписать всё в кадр. То же делает кнопка с рамкой в левом нижнем углу.

Имена таблиц в тексте живые. Наведи на <T id="public.author">author</T>, и её колонки подсветятся на доске. Кликнешь, и камера подлетит к таблице.

Теперь первый запрос. Нажми «На доску» под ним:

```sql run expect=rows:11
select * from book;
```

Над <T id="public.book">book</T> поднимается **призрак**: копия таблицы, на которой показывают, что делает запрос. Камера подлетает к нему, а сама доска бледнеет, чтобы не отвлекать. Внизу появляется результат: 11 строк. Это же число стоит в шапке таблицы.

## Редактор считает сам

Кнопки «Выполнить» нет. Редактор сам выполняет запрос примерно через четверть секунды после того, как ты перестал печатать. Это **превью**. Плашка под редактором напоминает: «Превью: база не меняется».

Сотри запрос в редакторе и набери этот руками. Или нажми «На доску», если лень:

```sql run expect=rows:11
select title, price from book;
```

Строк по-прежнему 11, а колонок осталось две. На шаге `SELECT` лишние колонки уходят из призрака. На доске у <T id="public.book">book</T> подсвечены колонки запроса. Остальные широкая таблица сворачивает в заглушку «+4 колонки», чтобы не расползаться по доске. Наведи на заглушку, и увидишь имена спрятанных колонок. После `select *` таблица снова видна целиком.

## Плеер

Полоса между доской и редактором и есть плеер. В ней чипы `FROM`, `WHERE`, `SELECT`: шаги запроса в логическом порядке. Пишешь ты с `SELECT`, а по смыслу запрос начинается с `FROM`: сначала откуда брать строки, потом какие из них оставить, и только в конце какие колонки показать. Клик по чипу перематывает сцену к этому шагу. Рядом кнопки «шаг назад», «играть» и «шаг вперёд», скорость 0.5x, 1x и 2x. Строка под чипами объясняет, что случилось на текущем шаге.

Пройди сцену сам. Первый шаг отправь кнопкой «На доску», дальше листай «Дальше»:

<Scene>
<Step caption="Все книги">

```sql run expect=rows:11
select book_id, title, price from book;
```

</Step>
<Step caption="Только книги с ценой">

```sql run expect=rows:10
select book_id, title, price from book where price is not null;
```

</Step>
<Step caption="Дороже 1000">

```sql run expect=rows:3
select book_id, title, price from book where price > 1000;
```

</Step>
</Scene>

Строк было 11, потом 10, потом 3. Кликни по чипу `WHERE` на втором шаге, и строка под чипами покажет «WHERE: осталось 10 из 11 строк». Ушёл «Остров погибших кораблей»: цены у него нет.

На третьем шаге там же будет «UNKNOWN у 1». Это снова «Остров»: про пустую цену нельзя сказать, больше она 1000 или нет. Такие строки `WHERE` тоже отбрасывает, подробно разберём в уроке про NULL.

## Превью не меняет данные

Превью выполняет запрос по-настоящему, но внутри **транзакции**, которую приложение сразу откатывает. Транзакция это пачка изменений, которые сохраняются все разом или не сохраняются вовсе. Попробуй обнулить цену книги:

{/* final-only: пошаговый разбор UPDATE появится в Ф9 */}

```sql run trace=final-only expect=rows:1
update book set price = 0 where book_id = 1 returning title, price;
```

В результате «Тихий Дон» с ценой 0.00 и пометка «UPDATE: 1». Для `UPDATE` плеер сейчас показывает только итог и пишет «Пока не анимируется: UPDATE». Пошаговый разбор изменений будет в главе про изменение данных. Плашка под редактором всё так же говорит «Превью: база не меняется».

## «Применить» меняет данные

Записать изменения в базу можно только кнопкой «Применить» под редактором или сочетанием `⌘⏎`. У примеров, которые меняют данные, вместо «На доску» стоит кнопка «Применить»:

```sql apply expect=rows:1
insert into author (name, country, born_year) values ('Лев Толстой', 'Россия', 1828) returning name;
```

Справа внизу всплывёт «Записано в базу». Камера подлетит к <T id="public.author">author</T>, таблица перерисуется уже с Толстым, а в шапке будет 7. Проверим запросом:

```sql run expect=rows:7
select * from author;
```

7 строк: было 6. Если применить вставку ещё раз, Толстых станет двое, потому что запрета на одинаковые имена у авторов нет.

Под редактором две кнопки на такой случай. «Отменить» убирает последнее применённое изменение. То же делает `⌘Z`, но только вне редактора: в редакторе он отменяет набор. «Сброс» спрашивает «Сбросить урок?» и после подтверждения возвращает данные к началу урока.

## Чего нет в выдаче и почему

- ❌ «Остров погибших кораблей» среди книг дороже 1000: у него не указана цена.
- ❌ «Тихий Дон» с ценой 0: превью откатило `UPDATE`, цена осталась 890.
- ❌ Лев Толстой в выдаче про книги: вставка добавила автора, книг у него в базе нет.

## Ловушки

<Callout kind="trap">
«UPDATE: 1» в превью не значит, что строка изменилась. Проверь цену «Тихого Дона» после примера с обнулением:

```sql run expect=rows:1
select title, price from book where book_id = 1;
```

Цена 890.00. Превью показало, что *было бы*, и откатилось. Новички правят данные в превью, уходят из урока и не находят изменений. Сохраняет только «Применить».
</Callout>

<Callout kind="note">
Если запрос считается слишком долго, песочница перезапускается и показывает уведомление «Песочница перезапущена». Упрости запрос и запусти снова.
</Callout>

## Проверь себя

1. Сколько книг вернёт `select title from book where price < 500;`? Сначала ответь, потом запусти.
2. Примени вставку Толстого трижды и нажми «Сброс». Сколько строк будет в `author`?
3. Сколько строк сейчас в <T id="public.author">author</T>? Посмотри на шапку таблицы на доске и проверь запросом.
