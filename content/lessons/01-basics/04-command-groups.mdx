<TlDr>Команды SQL помогают менять структуру и данные, управлять доступом и транзакциями. Их группы называют DDL, DML, DCL и TCL.</TlDr>

## Что есть в данных

На доске таблица <T id="public.book">book</T>: в ней 11 книг. У «Тихого Дона» номер 1, а у «Простого Python» и «Изучаем Python» автор не указан. Пока будем читать эти данные. Команды для изменений ниже приведены как примеры, без кнопки запуска.

## Сначала посмотрим на данные

Начальный запрос выбирает название первой книги по номеру:

```sql run expect=rows:1
select title from book order by book_id limit 1;
```

В результате одна строка: «Тихий Дон». На доске `SELECT` оставляет колонку `title`, сортировка учитывает `book_id`, а `LIMIT` оставляет одну строку. Сама таблица от чтения не меняется.

Команду `SELECT` иногда выделяют в отдельную группу **DQL** (Data Query Language, язык запросов к данным), а иногда относят к DML. Это разные способы группировки. На результат запроса они не влияют.

## DDL: структура

**DDL** (Data Definition Language, язык определения данных) используют, когда создают или меняют объекты базы. Например, такая команда создаёт отдельную таблицу списка желаний с двумя колонками:

```sql noexec
create table wishlist (
  id integer,
  title text
);
```

После создания в `wishlist` пока нет строк. `ALTER TABLE` меняет определение таблицы, например добавляет колонку. `DROP TABLE` удаляет таблицу целиком. Таблица `book` от этих примеров не меняется: в уроке они показаны для чтения.

Если коллега просит DDL таблицы, обычно ему нужен SQL, который описывает её структуру: имя, колонки, типы и ограничения.

## DML: содержимое таблиц

**DML** (Data Manipulation Language, язык управления данными) используют для работы со строками. Например, после создания `wishlist` можно добавить в неё книгу:

```sql noexec
insert into wishlist (id, title) values (1, 'Новая книга');
```

`INSERT` добавляет строки, `UPDATE` меняет значения в существующих строках, `DELETE` удаляет строки. Для изменения строк обычно указывают условие `WHERE`. Саму структуру `wishlist` эти команды не переопределяют.

<Callout kind="analogy">
Представь картотеку: DDL задаёт ящики и поля карточек, а DML помогает добавлять и исправлять карточки. Чтение карточки похоже на `SELECT`.
</Callout>

## DCL: доступ

**DCL** (Data Control Language, язык управления доступом) касается прав. `GRANT` выдаёт право, а `REVOKE` отзывает его. Например:

```sql noexec
grant select on book to reader;
```

Здесь `reader` это пример имени роли, которой дают право читать таблицу `book`. Выдача права на `SELECT` сама по себе не даёт права удалять строки. Роли `reader` в нашем наборе нет, поэтому пример оставлен без запуска.

## TCL: границы транзакции

**Транзакция** объединяет несколько действий в одну операцию. Её изменения можно зафиксировать или отменить вместе. Представь перенос двух записей между списками: если закончить только половину работы, сведения станут неверными.

**TCL** (Transaction Control Language, язык управления транзакциями) задаёт границы такой работы. В примере `BEGIN` начинает транзакцию, а `COMMIT` фиксирует вставку:

```sql noexec
begin;
insert into wishlist (id, title) values (2, 'Ещё одна книга');
commit;
```

Если вместо `COMMIT` выполнить `ROLLBACK`, незакреплённые изменения транзакции откатятся. Транзакция может включать разные команды, в том числе изменения структуры и данных. В песочнице TCL из примера не запускаем: превью само выполняет запрос внутри транзакции и откатывает его.

## Чего нет в выдаче и почему

Вернёмся к книгам без автора:

```sql run expect=rows:2
select title from book where author_id is null order by title;
```

На доске `WHERE` оставляет две строки, а остальные девять уходят из результата. Сама таблица по-прежнему содержит 11 книг: выборка ничего не удалила.

- «Тихий Дон» не попал в выдачу: номер автора указан.
- В первой выдаче не было «Простого Python»: `LIMIT 1` оставил книгу с наименьшим номером.

## Ловушки

<Callout kind="trap">
`DELETE` и `DROP TABLE` легко перепутать. Первая команда удаляет строки, вторая удаляет саму таблицу. У `DELETE` без `WHERE` условие отбора отсутствует:

```sql noexec
delete from wishlist;
```

В созданной выше таблице такой запрос удалит все строки; пустая таблица останется. Перед удалением проверь условие и сначала посмотри те же строки через `SELECT`.
</Callout>

2. Что вернёт первый запрос, если заменить `limit 1` на `limit 2`? Измени его в редакторе и проверь на доске.
3. Чем отличается `COMMIT` от `ROLLBACK`? Найди ответ в разделе о транзакциях.

<Cheatsheet>
- DDL: структура объектов. `CREATE`, `ALTER`, `DROP`.
- DML: работа с данными. `INSERT`, `UPDATE`, `DELETE`; `SELECT` также могут относить к DML.
- DQL: чтение данных, если `SELECT` выделяют в отдельную группу.
- DCL: права. `GRANT` выдаёт, `REVOKE` отзывает.
- TCL: транзакции. `BEGIN` начинает, `COMMIT` фиксирует, `ROLLBACK` откатывает.
</Cheatsheet>
